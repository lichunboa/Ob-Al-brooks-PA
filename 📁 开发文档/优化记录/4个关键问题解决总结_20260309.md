## ✅ 问题 2: "规则拒绝｜✅ Equation: P×R=0.65 > (1-P)=0.47 ✓" 含义

**含义解释**:

这是一个**矛盾的日志**，表示：
- `规则拒绝` = 交易被拒绝
- `P×R=0.65 > (1-P)=0.47 ✓` = Trader's Equation 通过（应该执行）

**可能原因**:
- P×R 通过了，但其他规则拒绝了（如：多周期冲突、阻力位、风险限制）
- 日志格式不清晰，没有说明具体拒绝原因

**解决方案**: 已添加显式的 P×R 日志（见问题 3）

## ✅ 问题 3: 添加 P×R 显式日志 + 全覆盖

**实施位置**: `tools/patrol_trade.py`

**优化内容**:

### 修改前:
```python
if metrics["pxr"] <= metrics["rhs"]:
    return False, f"P×R={metrics['pxr']:.2f} <= (1-P)={metrics['rhs']:.2f}，交易方程不成立"
return True, f"P×R={metrics['pxr']:.2f} > (1-P)={metrics['rhs']:.2f} ✓"
```

### 修改后:
```python
# 显式计算和日志
left = metrics["pxr"]
right = metrics["rhs"]
te = left - right

if left <= right:
    detailed_msg = (
        f"❌ P×R 不达标\n"
        f"   P={metrics['p']:.0%} R={metrics['r']:.2f}\n"
        f"   P×R={left:.3f} ≤ (1-P)={right:.3f}\n"
        f"   TE={te:.3f} (为负，期望值不足)"
    )
    return False, detailed_msg

detailed_msg = (
    f"✅ P×R 达标\n"
    f"   P={metrics['p']:.0%} R={metrics['r']:.2f}\n"
    f"   P×R={left:.3f} > (1-P)={right:.3f}\n"
    f"   TE={te:.3f} (正期望值)"
)
return True, detailed_msg
```

**效果**:
- 显示完整的 P、R、P×R、(1-P) 值
- 显示 TE (Trader's Equation) 值
- 清晰说明是否达标及原因
