## 三、发现的问题

### 严重：Kimi API 调用过于频繁
- **现象**: 每 ~3 秒调用一次 Kimi API，2 小时消耗 4% 周额度
- **根因**: 信号每分钟生成 × 多 agent 路由 × 多 turn 处理 = 高频调用
- **需修复**: 降低信号频率或增加去重/节流窗口

- 今日 1604 次 "Embedded agent failed"

- 影响时段 09:00-21:00
