# 后端数据架构分析

## 当前架构

```
┌─────────────────────────────────────────────────────────────────┐
│                         数据采集层                               │
├─────────────────────────────────────────────────────────────────┤
│  data-service (Python)                                          │
│  ├── Binance WebSocket (cryptofeed) ← 实时 K线数据              │
│  └── TimescaleDB (PostgreSQL)       ← 存储 candles_1m           │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                         信号检测层                               │
├─────────────────────────────────────────────────────────────────┤
│  signal-service (Python)                                        │
│  ├── PG Engine  ← 从 TimescaleDB 读取数据                        │
│  ├── 129条信号检测规则                                          │
│  ├── SignalPublisher ← 发布信号事件                              │
│  └── SQLite ← 存储 cooldown、history                            │
└─────────────────────────────────────────────────────────────────┘
                              ↓
├─────────────────────────────────────────────────────────────────┤
│                         API 服务层                               │
├─────────────────────────────────────────────────────────────────┤
│  api-service (FastAPI)                                          │
│  ├── REST API /api/v1/candles/{symbol}                          │
│  ├── REST API /api/v1/signals                                   │
│  ├── WebSocket /ws ← 新添加，当前只有模拟数据                   │
│  └── sync-service 代理 (策略列表等)                             │
└─────────────────────────────────────────────────────────────────┘
```

## 后端强大的数据收集能力

### 1. data-service (数据采集)
- **Binance WebSocket**: 实时采集 ~300 个币种的 1m K线
- **批量写入优化**: 3秒时间窗口批量写入，避免 DB 压力
- **缺口巡检**: 自动检测并补齐缺失的 K线数据
- **存储**: TimescaleDB (PostgreSQL 时序扩展)

### 2. signal-service (信号检测)
- **129条信号规则**: 涵盖趋势、动量、形态、波动率等
- **双引擎**: SQLite (本地缓存) + PostgreSQL (主数据源)
- **冷却机制**: 防止信号重复推送
- **i18n 支持**: 信号消息可国际化

### 3. api-service (对外服务)
- **REST API**: CoinGlass V4 风格
- **WebSocket**: 实时推送（刚添加）
- **代理**: 转发 sync-service 请求
