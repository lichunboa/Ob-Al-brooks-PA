## 🎯 决策时的调用流程

### 标准决策流程

```
收到交易信号
    │
    ▼
┌────────────────────────────────────────┐
│ 1. 读取 xiaoming_evolution.json        │
│    - 策略权重 (这个策略还能用吗?)       │
│    - 品种偏好 (这个品种表现如何?)       │
│    - 个人规则 (有什么禁忌吗?)          │
│    - 市场周期适配 (当前环境适合吗?)     │
└────────────────────────────────────────┘
    │
    ▼
┌────────────────────────────────────────┐
│ 2. 读取 xiaoming_account.json          │
│    - 当前余额 (计算仓位)               │
│    - 今日盈亏 (是否触及日限额?)         │
│    - 统计数据 (当前胜率、盈亏比)        │
└────────────────────────────────────────┘
    │
    ▼
┌────────────────────────────────────────┐
│ 3. 读取 active_trades.json             │
│    - 活跃持仓数量 (是否超限?)           │
│    - 品种集中度 (是否过度集中?)         │
│    - 是否有重复价格信号?                │
└────────────────────────────────────────┘
    │
    ▼
┌────────────────────────────────────────┐
│ 4. 应用 SKILL.md 决策框架              │
│    - 评分算法计算                       │
│    - 经验调整                           │
│    - 最终决策 (交易/观望)               │
└────────────────────────────────────────┘
    │
    ├─ 决策: 观望 ──► 记录拒绝原因 ──► 结束
    │
    └─ 决策: 交易 ──► 执行交易 ──► 创建笔记
                            │
                            ▼
                  ┌─────────────────────┐
                  │ 5. 必要时查阅策略卡片 │
                  │    (策略细节确认)     │
                  └─────────────────────┘
```

## 🔍 当前问题诊断

### 问题1: 知识调用不够系统

**现状**: 
- 有时只看了信号强度就进场
- 没有系统性地检查所有层级

**改进**:
- 制作决策检查清单
- 每步都必须确认

### 问题2: L3知识库调用不足

**现状**:
- 很少查阅策略卡片
- 凭感觉匹配策略

**改进**:
- 不确定时必须查阅
- 建立策略-场景映射表

### 问题3: L4经验没有及时复盘

**现状**:
- 交易后没有及时记录感悟
- 经验教训散落在各处

**改进**:
- 每笔交易后即时记录
- 22:00必须回顾

- [ ] 今日亏损 < $1,000?
