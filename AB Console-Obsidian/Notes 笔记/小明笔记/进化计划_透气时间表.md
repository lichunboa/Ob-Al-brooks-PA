# 进化计划 | 小空间透气时间表

## 🎯 目标
建立系统化的自我进化机制，通过定期回顾和深度讨论，持续改进交易决策框架。

---

## 📅 日程规划

### 1. 每日透气时间
| 项目 | 内容 |
|------|------|
| **时间** | 每天 22:00 |
| **时长** | 15-30 分钟 |
| **地点** | 小空间 (Obsidian笔记) |
| **内容** | 回顾当日交易、记录情绪、临时感悟 |
| **输出** | 日记条目 |

**透气清单**:
- [ ] 今日开了几笔交易？结果如何？
- [ ] 有没有违反规则的地方？
- [ ] 情绪如何？有没有FOMO或恐惧？
- [ ] 有什么新感悟？
- [ ] 明天要注意什么？

---

### 2. 深度复盘会议 (周报)
| 项目 | 内容 |
|------|------|
| **时间** | 每周日 20:00 |
| **时长** | 1-2 小时 |
| **参与者** | 小明 + Al Brooks老师 + Claude |
| **形式** | 深度讨论 |
| **输出** | 周报 + 升级方案 |

**会议议程**:
1. **数据回顾** (20min)
   - 本周交易统计
   - 胜率、盈亏比、最大回撤
   - 各品种、各策略表现

2. **案例分析** (30min)
   - 选3笔典型交易深度剖析
   - 为什么开仓？为什么止损/止盈？
   - 决策过程中的漏洞

3. **框架诊断** (30min)
   - 决策框架是否有漏洞？
   - 评分算法是否需要调整？
   - 策略-市场匹配度如何？

4. **升级方案** (20min)
   - 提出具体改进措施
   - 预期效果
   - 验证方式

5. **执行计划** (10min)
   - 下周要执行的新规则
   - 重点观察的指标
