## 🔄 Al Brooks PA 转化映射表

### 核心概念转化

| 原概念 | Al Brooks 术语 | 说明 |
|--------|---------------|------|
| **趋势判断** | Always In Direction (AID) | 当前市场的主导方向 |
| **趋势强度** | Trend Strength (Strong/Weak) | 通过K线形态判断 |
| **方向确认** | Higher High/Higher Low (HH/HL) | 趋势结构确认 |
| **震荡市** | Trading Range (TR) | 无明确方向的区间 |
| **突破** | Breakout (BO) | 价格突破关键位 |
| **回调** | Pullback (PB) | 趋势中的反向运动 |
| **假突破** | Failed Breakout (FB) | 突破后快速反转 |
| **支撑阻力** | Magnet (磁铁) | 价格吸引点 |
| **入场信号** | Signal Bar | 触发入场的K线 |
| **确认K线** | Entry Bar | 实际入场的K线 |
| **止损位** | Initial Stop | 初始止损位置 |
| **移动止损** | Trailing Stop | 跟踪止损 |
| **目标位** | Measured Move (MM) | 等距测量目标 |

### 市场周期转化

| 原概念 | Al Brooks 周期 | 特征 |
|--------|---------------|------|
| 强趋势 | Spike / Strong Trend | 连续同向K线，少回调 |
| 弱趋势 | Weak Trend / Channel | 有回调但方向明确 |
| 震荡 | Trading Range | 上下边界震荡 |
| 突破 | Breakout Mode | 区间突破初期 |
| 反转 | Reversal | 趋势末期转向 |

### 入场信号转化

| 原信号类型 | Al Brooks 策略 | 适用周期 |
|-----------|---------------|---------|
| 趋势跟随 | Buy/Sell NOW (市价追进) | 急速行情 |
| 回调入场 | High 1/Low 1 (高1/低1) | 趋势延续 |
| 均线回调 | 20 EMA Gap (20均线缺口) | 趋势回调 |
| 突破回调 | Breakout Pullback | 突破模式 |
| 区间反转 | Double Top/Bottom | 区间边界 |
| 假突破 | Failed Breakout (失败突破) | 交易区间 |
| 磁铁交易 | Rush to Magnet (急赴磁体) | 交易区间 |
| 楔形反转 | Wedge Top/Bottom | 反转 |
| 通道反转 | Spike and Channel | 反转 |
| 旗形反转 | Final Flag (末端旗形) | 反转 |

### 出场策略转化

| 原概念 | Al Brooks 术语 | 计算方式 |
|--------|---------------|---------|
| 固定止损 | Initial Stop | Signal Bar 极值外 |
| 移动止损 | Trailing Stop | 跟踪HH/LL |
| 固定止盈 | Measured Move | 等距测量 |
| 分批止盈 | Scale Out | 部分仓位先出 |
| 保本止损 | Breakeven Stop | 移动到入场价 |

## 📝 核心文件内容模板

### 00_交易决策检查清单.md

```markdown
# 交易决策检查清单 v1.0

## 🚦 入场前检查 (必须全部通过)

### Step 1: 方向确认
- [ ] Always In 方向明确? (Long/Short/Neutral)
- [ ] 与信号方向一致?

### Step 2: 周期识别
- [ ] 当前市场周期? (急速/趋势/区间/反转)
- [ ] 策略与周期匹配?

### Step 3: 策略验证
- [ ] 策略权重 ≥ 50?
- [ ] 品种权重 ≥ 60?
- [ ] 入场条件全部满足?

### Step 4: 风控检查
- [ ] 今日亏损 < $1,000?
- [ ] 活跃持仓 < 10笔?
- [ ] 盈亏比 ≥ 2:1?

### Step 5: 执行确认
- [ ] 止损位置明确?
- [ ] 止盈目标明确?
- [ ] 仓位计算正确?

## ⚠️ 红线 (任一触发则放弃)
- 今日亏损 ≥ $1,000
- 连续亏损 ≥ 5笔
- 策略权重 < 50
- 盈亏比 < 1.5:1
```

| **反转** | 极速与通道 | 末端旗形 | 趋势跟随 |

## 策略权重速查
