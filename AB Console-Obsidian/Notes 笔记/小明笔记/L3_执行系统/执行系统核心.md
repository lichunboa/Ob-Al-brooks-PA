# 小明技能树 | L3 执行系统

> **基于 Al Brooks 交易方程**
> **调用时机**: 入场/出场决策时

---

## 0. PA 信号入场流程

### 信号接收后的决策流程

```
收到 PA 信号 → 检查信号强度 (≥70?) → 检查入场条件
    → 确认止损/止盈 → 选择入场方式 → 执行交易
```

### 信号字段解读

| 字段 | 含义 | 决策用途 |
|------|------|---------|
| `entry_type=STOP` | 止损单入场 | 等待突破 `entry_trigger` 价格 |
| `entry_type=LIMIT` | 限价单入场 | 在 `entry_trigger` 挂单等待 |
| `entry_type=MARKET` | 市价入场 | 立即入场（急速行情） |
| `confirmation_needed=true` | 需要确认 | 等待下一根 K 线确认 |

### 入场触发价使用

- **做多 (BUY)**: 当价格突破 `entry_trigger` 时入场
- **做空 (SELL)**: 当价格跌破 `entry_trigger` 时入场
- **信号 K 线范围**: `signal_bar_high` ~ `signal_bar_low`

## 1. 入场规则

### 入场检查清单

- [ ] Always In 方向确认？
- [ ] 市场周期识别？
- [ ] 信号 K 线有效？
- [ ] 盈亏比 ≥ 2:1？
- [ ] 止损位置明确？
- [ ] **PA 信号强度 ≥ 70？**
- [ ] **入场触发价合理？**

### 入场方式

| 类型 | 场景 | 风险 | PA 信号对应 |
|------|------|------|------------|
| **止损单入场** | 突破确认 | 中 | `entry_type=STOP` |
| **限价单入场** | 回调入场 | 需更强信号 | `entry_type=LIMIT` |
| **市价单入场** | 急速行情 | 高，需经验 | `entry_type=MARKET` |

## 2. 止损止盈

### 止损设置

| 类型 | 位置 | 说明 | PA 信号字段 |
|------|------|------|------------|
| 初始止损 | Signal Bar 极值外 | 必须设置 | `stop_loss` |
| 跟踪止损 | 跟随 HH/LL | 趋势中使用 | - |
| 保本止损 | 移到入场价 | 利润保护 | - |

### 止盈设置

| 方法 | 说明 | PA 信号字段 |
|------|------|------------|
| **等距测量** | 第 1 腿 = 第 2 腿 | `extra.measured_move_target` |
| **固定目标** | 信号给出的目标位 | `take_profit` |
| **磁铁位** | 前高/前低、整数关口 | - |
| **分批出场** | 50% 先出，剩余跟踪 | - |

## 3. 仓位管理

### 仓位计算

```
仓位 = 账户 × 风险比例 / 止损点数
止损点数 = |entry_trigger - stop_loss|
```

| 模式 | 仓位比例 | 用途 | 信号强度要求 |
|------|---------|------|-------------|
| 标准 | 1% | 正常交易 | ≥ 75 |
| 实验 | 0.1% | 测试新策略 | ≥ 70 |
| 保守 | 0.5% | 连续亏损后 | ≥ 80 |
| 激进 | 2% | 高确信度 | ≥ 85 |

## 4. 风控红线

| 红线 | 阈值 | 触发动作 |
|------|------|---------|
| 日亏损 | $1,000 | 停止当日交易 |
| 连续亏损 | 10 笔 | 暂停 24 小时 |
| 总回撤 | 50% | 全面复盘 |
| **同向持仓** | 3 笔 | 不再开新仓 |
| **反向信号** | 收到 | 考虑平仓 |

## 5. 时段调整

根据 PA 信号的 `extra.session` 字段调整策略：

| 时段 | 特点 | 建议 |
|------|------|------|
| 亚洲 | 波动小 | 降低仓位，谨慎突破 |
| 欧洲 | 波动增加 | 标准仓位 |
| 美洲 | 波动最大 | 可适当加仓 |
| 收盘 | 波动降低 | 减少交易 |
