## 2. 策略权重机制

### 初始权重

11 个 Al Brooks 策略的初始权重设为 **0.5**（50%），而非 1.0。

这意味着：
- 信号强度 = 原始强度 × 策略权重
- 初始时，80 分信号 → 实际 40 分
- 需要通过实战验证才能提升权重

### 权重计算公式

```
新权重 = 当前权重 × (1 + 学习率 × 表现分数)

表现分数 = (胜率 - 0.5) × 2 + (盈亏比 - 2) × 0.2

学习率 = 0.1（每次交易后调整 10%）
```

### 权重范围

| 状态 | 权重范围 | 说明 |
|------|---------|------|
| 禁用 | 0.0 | 连续失败，暂时禁用 |
| 观察 | 0.1 - 0.3 | 表现差，降低使用 |
| 正常 | 0.4 - 0.7 | 默认状态 |
| 优先 | 0.8 - 1.0 | 表现好，优先使用 |
| 核心 | 1.0+ | 验证有效，可加仓 |

## 3. 降权恢复机制

### 时间衰减

被降权的策略不会永久禁用，设置**恢复周期**：

| 降权程度 | 恢复周期 | 恢复方式 |
|---------|---------|---------|
| 轻度 (0.3-0.5) | 24 小时 | 自动恢复 0.1 |
| 中度 (0.1-0.3) | 72 小时 | 自动恢复 0.05 |
| 重度 (0.0-0.1) | 7 天 | 需手动确认恢复 |

### 恢复公式

```
每日恢复量 = (0.5 - 当前权重) × 0.1

# 示例：权重 0.2 → 每日恢复 (0.5-0.2)×0.1 = 0.03
# 约 10 天恢复到 0.5
```

### 强制恢复条件

即使权重很低，以下情况强制恢复到 0.3：
- 市场环境变化（从区间转趋势）
- 连续 3 次该策略信号被忽略后盈利
- 手动触发复盘确认

## 4. 信号源分类

### Al Brooks 核心信号（主权重）

这些信号直接影响交易决策：

| 信号源 | 权重 | 说明 |
|--------|------|------|
| **PA 引擎 11 策略** | 0.5-1.0 | 核心入场信号 |
| **EMA20 位置** | 0.8 | 趋势判断 |
| **支撑阻力** | 0.7 | 目标位/止损位 |
| **成交量确认** | 0.6 | 突破有效性 |

### 辅助信号（加权）

这些信号用于增强或削弱主信号：

| 信号源 | 加权范围 | 用途 |
|--------|---------|------|
| **RSI 背离** | +10/-10 | 反转确认 |
| **RSI 超买超卖** | +5/-5 | 极端位置警告 |
| **大户多空比** | +8/-8 | 情绪确认 |
| **OI 连续** | +5/-5 | 趋势强度 |
| **情绪翻转** | +15/-15 | 重要反转信号 |
| **资金费率** | +3/-3 | 极端情绪 |
| **MACD 背离** | +8/-8 | 趋势衰竭 |
| **布林带位置** | +5/-5 | 波动率参考 |

### 信号融合公式

```
最终信号强度 = PA信号强度 × 策略权重 + Σ(辅助信号加权)

# 示例：
PA 信号: 80 分，策略权重 0.6
RSI 底背离: +10
大户看多: +8
OI 增仓: +5

最终强度 = 80 × 0.6 + 10 + 8 + 5 = 71 分
```

## 5. 实战升级路径

### 策略毕业条件

从"观察"升级到"正常"：
- 连续 5 笔盈利
- 胜率 > 50%
- 平均盈亏比 > 1.5

从"正常"升级到"优先"：
- 连续 10 笔盈利
- 胜率 > 55%
- 平均盈亏比 > 2.0

从"优先"升级到"核心"：
- 连续 20 笔盈利
- 胜率 > 60%
- 平均盈亏比 > 2.5

### 小明自创策略

当小明发现新模式时：
1. 记录到 `L3_经验积累/策略实验日志/`
2. 初始权重 0.1（实验模式）
3. 仓位限制 0.1%
4. 验证 5 次后可升级
