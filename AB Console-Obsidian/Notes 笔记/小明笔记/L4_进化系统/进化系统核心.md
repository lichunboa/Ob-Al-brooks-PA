## 0. 信号反馈闭环

### Al Brooks PA 信号接收

小明通过 Webhook 接收后端 PA 引擎的信号，信号包含：

| 字段 | 说明 | 用途 |
|------|------|------|
| `signal_type` | 策略名称 | 匹配 11 张策略卡片 |
| `direction` | BUY/SELL | 交易方向 |
| `strength` | 0-100 | 信号强度（≥70 才推送） |
| `cycle` | 市场周期 | 急速/趋势/区间/反转 |
| `entry_trigger` | 入场触发价 | 止损单入场价 |
| `stop_loss` | 止损价 | 风控必填 |
| `take_profit` | 止盈价 | 目标位 |
| `probability` | 概率 | Al Brooks 概率规则 |
| `extra.session` | 交易时段 | 亚洲/欧洲/美洲/收盘 |
| `extra.measured_move_target` | 等距测量目标 | AB=CD 目标位 |

### 信号处理流程

```
PA 引擎检测 → SignalPublisher 发布 → Webhook 推送
    → 小明接收 → 创建交易笔记 → 追踪结果 → 反馈学习
```

### 反馈记录

每笔交易结束后，记录到 `L3_经验积累/信号反馈/`：

```markdown
# 信号反馈: [信号ID]

## 信号信息
- 策略: 20均线缺口
- 方向: BUY
- 强度: 82
- 时段: 美洲

## 结果
- 入场: 97500
- 出场: 98200
- 盈亏: +700
- 结果: 止盈

## 学习点
- 信号准确性: ✅
- 入场时机: ✅
- 止损设置: 合理
- 改进建议: 无
```

## 1. 每日复盘 (22:00)

### 复盘流程

1. **统计今日交易**
   - 开仓数、止损数、止盈数
   - 净盈亏

2. **核心法则对照检查**
   - 今日是否正确判断 Always In？
   - 是否遵守了核心法则？
   - 哪些法则被违反？记录学习点

3. **策略表现分析**
   - 哪个策略表现最好？
   - 是否有新模式发现？
   - **PA 信号准确率统计**

4. **更新配置**
   - 调整策略权重
   - 记录教训
   - **更新信号过滤阈值**

### 输出

- evolution_log.json 追加
- 策略权重更新
- **信号反馈汇总**

## 2. 每周复盘 (周日 20:00)

### 复盘内容

1. **汇总本周交易**
2. **分析策略/品种表现**
3. **核心法则统计**
   - 哪些法则遵守收益最好？
   - 哪些法则违反最多？
4. **PA 信号质量分析**
   - 各策略信号准确率
   - 各时段信号表现
   - 等距测量目标达成率
5. **提出升级建议**

### 输出

- 周复盘报告
- SKILL.md 升级建议（需确认）
- **PA 引擎参数调优建议**

```
发现新模式 → 记录假设 → 实验交易（0.1%仓位）
```

## 4. 信号质量追踪

### 追踪指标

| 指标 | 计算方式 | 目标 |
|------|---------|------|
| 信号准确率 | 盈利信号数 / 总信号数 | ≥ 50% |
| 平均盈亏比 | 平均盈利 / 平均亏损 | ≥ 2:1 |
| 时段表现 | 各时段胜率 | 识别最佳时段 |
| 策略表现 | 各策略胜率 | 识别最佳策略 |

### 自动调优

根据追踪数据，自动调整：
- 信号强度阈值（默认 70）
- 时段权重系数
- 策略优先级
