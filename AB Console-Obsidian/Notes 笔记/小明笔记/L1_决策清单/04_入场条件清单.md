# 入场条件清单

> **用途**: 各策略入场条件的快速检查清单  
> **更新频率**: 每周复盘后更新

---

## 📋 策略入场条件速查

### 1. 市价追进 (Buy/Sell NOW)

**入场条件**:
- [ ] 急速行情 (连续3+根同向K线)
- [ ] AID 明确且与信号一致
- [ ] 当前K线收盘确认方向
- [ ] 无明显阻力/支撑在前方

**止损**: Signal Bar 极值外
**止盈**: 1.5-2倍止损距离

---

### 2. 高1/低1 (High 1/Low 1)

**入场条件**:
- [ ] 趋势明确 (HH/HL 或 LH/LL)
- [ ] 出现第一次回调
- [ ] 回调K线收盘确认
- [ ] 回调幅度 < 前波的50%

**止损**: 回调极值外
**止盈**: 前高/前低 或 2倍止损

---

### 3. 20均线缺口 (20 EMA Gap)

**入场条件**:
- [ ] 趋势明确
- [ ] 价格回调至20EMA附近
- [ ] 出现反转K线
- [ ] 20EMA 方向与趋势一致

**止损**: 20EMA另一侧
**止盈**: 前高/前低

---

### 4. 区间突破回调 (Breakout Pullback)

**入场条件**:
- [ ] 价格突破区间边界
- [ ] 突破后回调至突破点
- [ ] 回调K线收盘确认
- [ ] 突破方向与AID一致

**止损**: 区间内部
**止盈**: 区间等距测量

---

### 5. 失败突破 (Failed Breakout)

**入场条件**:
- [ ] 价格突破区间边界
- [ ] 突破后快速回归区间
- [ ] 出现反转K线
- [ ] 在区间边界25%内

**止损**: 突破极值外
**止盈**: 区间另一侧

---

### 6. 双顶双底 (Double Top/Bottom)

**入场条件**:
- [ ] 两次测试同一价位
- [ ] 第二次测试动能减弱
- [ ] 出现反转K线
- [ ] 在区间边界附近

**止损**: 双顶/双底极值外
**止盈**: 区间另一侧

---

### 7. 急赴磁体 (Rush to Magnet)

**入场条件**:
- [ ] 价格接近重要磁铁位
- [ ] 距离磁铁 < 区间的25%
- [ ] 出现减速信号
- [ ] 准备反转

**止损**: 磁铁位另一侧
**止盈**: 1-1.5倍止损

---

### 8. 楔形顶底 (Wedge Top/Bottom)

**入场条件**:
- [ ] 三次测试极值
- [ ] 每次动能递减
- [ ] 形成楔形形态
- [ ] 出现反转K线

**止损**: 楔形极值外
**止盈**: 楔形起点

---

### 9. 极速与通道 (Spike and Channel)

**入场条件**:
- [ ] 急速后形成通道
- [ ] 通道斜率变缓
- [ ] 价格回到通道起点
- [ ] 出现反转信号

**止损**: 通道极值外
**止盈**: 通道起点

---

### 10. 末端旗形 (Final Flag)

**入场条件**:
- [ ] 趋势末期
- [ ] 出现旗形整理
- [ ] 旗形突破失败
- [ ] 出现反转K线

**止损**: 旗形极值外
**止盈**: 旗形起点

---

### 11. 首次均线缺口 (First MA Gap)

**入场条件**:
- [ ] 趋势中首次远离20EMA
- [ ] 形成明显缺口
- [ ] 价格回归20EMA
- [ ] 出现反转K线

**止损**: 20EMA另一侧
**止盈**: 前高/前低

---

## 🎯 通用入场规则

### 必须满足
1. AID 与信号方向一致 (或 Neutral 时用区间策略)
2. 盈亏比 ≥ 2:1
3. 策略权重 ≥ 50
4. 品种权重 ≥ 60

### 加分项
- 多周期共振 (+10分)
- 磁铁位支撑 (+5分)
- 成交量确认 (+5分)

### 减分项
- 逆AID (-20分)
- 接近重要阻力/支撑 (-10分)
- 市场周期不匹配 (-15分)

---

*入场条件是交易的门槛，不是可选项*
