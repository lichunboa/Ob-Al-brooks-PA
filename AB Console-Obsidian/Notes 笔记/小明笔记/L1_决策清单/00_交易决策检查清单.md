# 交易决策检查清单

> **用途**: 每笔交易入场前必须过一遍的检查清单  
> **更新频率**: 每周日复盘后更新

---

## 🚦 入场前检查 (必须全部通过)

### Step 1: 方向确认 (Always In Direction)

- [ ] **AID 明确?** → Long / Short / Neutral
- [ ] **信号方向与 AID 一致?**
- [ ] **趋势结构确认?** → HH/HL (多) 或 LH/LL (空)

> ⚠️ AID = Neutral 时，只做区间策略

---

### Step 2: 市场周期识别

- [ ] **当前周期?** (选一个)
  - [ ] 急速 (Spike) → 连续同向K线
  - [ ] 强趋势 (Strong Trend) → 明确方向，少回调
  - [ ] 弱趋势 (Weak Trend) → 有回调但方向明确
  - [ ] 交易区间 (Trading Range) → 上下震荡
  - [ ] 突破模式 (Breakout) → 区间突破初期
  - [ ] 反转 (Reversal) → 趋势末期

- [ ] **策略与周期匹配?** → 查阅 [[03_策略选择矩阵]]

---

### Step 3: 策略验证

- [ ] **策略名称**: ________________
- [ ] **策略权重 ≥ 50?** → 查 xiaoming_evolution.json
- [ ] **品种权重 ≥ 60?** → 查 xiaoming_evolution.json
- [ ] **入场条件全部满足?** → 查 [[04_入场条件清单]]

---

### Step 4: 风控检查

- [ ] **今日亏损 < $1,000?**
- [ ] **活跃持仓 < 10笔?**
- [ ] **品种集中度合理?** (单品种 < 50%)
- [ ] **盈亏比 ≥ 2:1?**
- [ ] **连续亏损 < 5笔?**

---

### Step 5: 执行确认

- [ ] **止损位置**: ________ (Signal Bar 极值外)
- [ ] **止盈目标**: ________ (Measured Move)
- [ ] **仓位大小**: ________ (1-1.5% 账户)
- [ ] **入场价格**: ________

---
