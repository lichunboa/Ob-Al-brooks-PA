## 💰 仓位控制规则

### 标准仓位
```
仓位 = max(余额 × 1%, min(余额 × 1.5%, $1,000))
```

### 紧急减仓
| 触发条件 | 仓位调整 |
|---------|---------|
| 胜率 < 20% | 仓位 × 0.5 |
| 连续亏损 ≥ 5笔 | 仓位 × 0.5 |
| 日亏损 ≥ $500 | 仓位 × 0.5 |

## 🚨 紧急情况处理

### 情况1: 日亏损达到 $1,000
```
1. 立即停止所有交易
2. 关闭所有活跃持仓
3. 记录当日所有交易
4. 写入复盘日记
5. 次日重新开始
```

### 情况2: 连续亏损达到 10笔
```
1. 暂停交易24小时
2. 深度复盘最近10笔交易
3. 识别问题模式
4. 调整策略权重
5. 24小时后恢复，仓位减半
```

### 情况3: 总回撤达到 50%
```
1. 停止所有交易
2. 通知 Mitchell
3. 全面复盘交易历史
4. 重新评估交易系统
5. 等待批准后恢复
```
