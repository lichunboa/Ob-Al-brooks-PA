# 市场周期识别

> **用途**: 快速识别当前市场所处的周期阶段  
> **更新频率**: 每月复盘后更新

---

## 🔄 六大市场周期

### 1. 急速 (Spike)
**特征**:
- 连续3+根同向K线
- 几乎无回调
- 动能极强

**识别清单**:
- [ ] 连续同向K线 ≥ 3根
- [ ] 回调 < 前一根K线的25%
- [ ] 成交量放大

**适用策略**: 市价追进、高1/低1

---

### 2. 强趋势 (Strong Trend)
**特征**:
- HH/HL 或 LH/LL 结构清晰
- 回调浅，不超过前波的38%
- 20EMA 提供支撑/阻力

**识别清单**:
- [ ] 趋势结构明确 (HH/HL 或 LH/LL)
- [ ] 回调 < 38% Fibonacci
- [ ] 价格尊重20EMA

**适用策略**: 高1/低1、20均线缺口

---

### 3. 弱趋势 (Weak Trend)
**特征**:
- 方向明确但回调较深
- 回调可达50-61.8%
- 趋势线斜率较缓

**识别清单**:
- [ ] 方向明确但动能减弱
- [ ] 回调 > 38% Fibonacci
- [ ] 经常测试20EMA

**适用策略**: 区间突破回调、首次均线缺口

---

### 4. 交易区间 (Trading Range)
**特征**:
- 价格在上下边界震荡
- 无明确方向
- 假突破频繁

**识别清单**:
- [ ] 上下边界明确
- [ ] 价格在区间内震荡 ≥ 20根K线
- [ ] 突破后快速回归

**适用策略**: 失败突破、双顶双底、急赴磁体

---

### 5. 突破模式 (Breakout)
**特征**:
- 刚突破区间
- 方向待确认
- 可能是真突破或假突破

**识别清单**:
- [ ] 价格突破区间边界
- [ ] 突破K线实体较大
- [ ] 等待回调确认

**适用策略**: 区间突破回调

---

### 6. 反转 (Reversal)
**特征**:
- 趋势末期
- 动能衰竭
- 出现反转形态

**识别清单**:
- [ ] 趋势持续较长时间
- [ ] 动能递减 (K线变小)
- [ ] 出现反转K线形态

**适用策略**: 极速与通道、末端旗形、楔形顶底

---

## 📊 周期识别流程图

```
开始
  │
  ▼
连续3+根同向K线? ──是──► 急速 (Spike)
  │
  否
  ▼
HH/HL或LH/LL结构? ──否──► 交易区间 (Trading Range)
  │
  是
  ▼
回调 < 38%? ──是──► 强趋势 (Strong Trend)
  │
  否
  ▼
回调 < 62%? ──是──► 弱趋势 (Weak Trend)
  │
  否
  ▼
刚突破区间? ──是──► 突破模式 (Breakout)
  │
  否
  ▼
动能衰竭+反转形态? ──是──► 反转 (Reversal)
  │
  否
  ▼
重新评估
```

---

## 🎯 周期→策略速查

| 周期 | 首选策略 | 禁用策略 |
|------|---------|---------|
| 急速 | 市价追进 | 区间策略 |
| 强趋势 | 高1/低1 | 逆势策略 |
| 弱趋势 | 区间突破回调 | 市价追进 |
| 交易区间 | 失败突破 | 趋势策略 |
| 突破模式 | 区间突破回调 | 逆势策略 |
| 反转 | 极速与通道 | 趋势跟随 |

---

## ⚠️ 常见错误

1. **把弱趋势当强趋势**: 导致追高被套
2. **把区间当趋势**: 导致假突破亏损
3. **错过反转信号**: 在趋势末期继续追
