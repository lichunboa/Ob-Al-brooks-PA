# 止损止盈规则

> **用途**: 止损止盈的计算和执行规则  
> **更新频率**: 每月复盘后更新

---

## 🛑 止损规则

### 止损位置计算

| 策略类型 | 止损位置 | 说明 |
|---------|---------|------|
| 趋势跟随 | Signal Bar 极值外 | 多头: 信号K线最低点下方 |
| 回调入场 | 回调极值外 | 回调K线的极值外 |
| 区间策略 | 区间边界外 | 突破区间边界即止损 |
| 反转策略 | 反转形态极值外 | 双顶/楔形等极值外 |

### 止损距离限制

| 限制类型 | 阈值 | 说明 |
|---------|------|------|
| 最小止损 | 0.3% | 避免被噪音扫损 |
| 最大止损 | 1.5% | 控制单笔风险 |
| 绝对最大 | $500 | 单笔亏损上限 |

### 止损执行规则

1. **止损必须在入场前设定**
2. **止损一旦设定，只能收紧，不能放宽**
3. **止损触发后立即执行，不犹豫**
4. **止损执行率目标: 100%**

## 🎯 止盈规则

### 止盈目标计算

| 方法 | 计算方式 | 适用场景 |
|------|---------|---------|
| 固定倍数 | 止损距离 × 2 | 默认方法 |
| 等距测量 (MM) | 前波幅度等距投射 | 趋势行情 |
| 磁铁位 | 下一个重要支撑/阻力 | 区间行情 |
| 区间边界 | 区间另一侧 | 区间策略 |

### 止盈策略

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| 全部止盈 | 到达目标全部平仓 | 区间策略 |
| 分批止盈 | 50%先出，50%跟踪 | 趋势策略 |
| 跟踪止盈 | 移动止损跟踪利润 | 强趋势 |

---

## 📐 盈亏比计算

### 公式
```
盈亏比 = (止盈价 - 入场价) / (入场价 - 止损价)
```

### 最低要求

| 策略类型 | 最低盈亏比 | 理想盈亏比 |
|---------|-----------|-----------|
| 趋势跟随 | 2:1 | 3:1 |
| 回调入场 | 2:1 | 2.5:1 |
| 区间策略 | 1.5:1 | 2:1 |
| 反转策略 | 2:1 | 3:1 |

### 盈亏比检查
- [ ] 盈亏比 ≥ 1.5:1 (最低要求)
- [ ] 盈亏比 ≥ 2:1 (标准要求)
- [ ] 盈亏比 ≥ 3:1 (理想情况)

## 🔄 移动止损规则

### 移动止损时机

| 条件 | 动作 |
|------|------|
| 盈利 ≥ 1倍止损 | 移动止损到入场价 (保本) |
| 盈利 ≥ 1.5倍止损 | 移动止损到 +0.5倍止损 |
| 盈利 ≥ 2倍止损 | 移动止损到 +1倍止损 |
| 新高/新低形成 | 移动止损到新的HH/LL |

### 移动止损方法

1. **固定比例法**: 每盈利1倍止损，移动止损0.5倍
2. **结构跟踪法**: 跟踪HH/HL (多头) 或 LH/LL (空头)
3. **均线跟踪法**: 跟踪20EMA

## 📊 止损止盈示例

### 示例1: 趋势跟随 (多头)

```
入场价: $100
止损价: $98 (Signal Bar 低点下方)
止损距离: $2 (2%)

止盈目标: $104 (2倍止损)
盈亏比: 2:1 ✅

移动止损:
- 价格到 $102 → 止损移到 $100 (保本)
- 价格到 $103 → 止损移到 $101
- 价格到 $104 → 止盈平仓
```

### 示例2: 区间策略 (做空)

```
入场价: $100 (区间顶部)
止损价: $101 (区间上方)
止损距离: $1 (1%)

止盈目标: $98 (区间底部)
盈亏比: 2:1 ✅

移动止损:
- 价格到 $99 → 止损移到 $100 (保本)
- 价格到 $98 → 止盈平仓
```

## ⚠️ 常见错误

1. **不设止损**: 导致大亏损
2. **止损太紧**: 被噪音扫损
3. **止损太宽**: 单笔亏损过大
4. **移动止损太快**: 被正常回调扫出
5. **不执行止损**: 抱有侥幸心理
