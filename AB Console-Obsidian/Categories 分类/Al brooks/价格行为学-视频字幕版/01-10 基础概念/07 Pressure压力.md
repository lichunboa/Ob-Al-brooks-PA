# 07 Pressure压力

> **Al Brooks**: "买方和卖方都在同时创造压力。牛市会尽量买更多的股票，以推动价格上升。熊市卖出以使得价格下降。"

## 📖 原文逐段解析

### 【段落1】压力的基本概念

> 大家好，我是艾尔布鲁克斯，这是我的价格行为交易教程第七讲。这一讲我们来讲买方卖方压力。K线通常可以显示熊市或者牛市谁更强。倾向于牛市的价格行为被称为买方压力。倾向于熊市的价格行为被称为卖方压力。

**【压力定义】** 📊
- **买方压力**：倾向于牛市的价格行为
- **卖方压力**：倾向于熊市的价格行为

> 买方和卖方都在同时创造压力。牛市会尽量买更多的股票，以推动价格上升。熊市卖出以使得价格下降，它们所形成的走势图就显示出了压力。

**【Al Brooks金句】** 💡
> "买方和卖方都在同时创造压力。"

---

### 【段落2】买方压力

> 在一个牛市当中，如果买方的压力处于优势。那就说明买方处于控制地位。未来走势就受买方压力为主导，所以对于一个牛市趋势，你又知道买方处于控制。因为你看到了买方的压力，牛市处于控制。

**【判断依据】** 👀
- 买方压力优势 → 买方控制 → 未来走势买方主导

> 有很多信号。买方压力的信号有哪些呢？这里有一个列表，我不能一次把所有的列表讲到。我来分部分的讲。

**【买方压力信号】** 📈

> 买方压力处于控制地位的一个明显指标就是走势图上的阳线。多于阴线，阳线大于阴线。而直阳线都是连续的，比如连续三个。连续四个。势头也非常强劲，实体很长，尾部很短。

**【信号1】** ⭐
- 阳线多于阴线
- 阳线大于阴线
- 阳线连续（3个、4个...）
- 实体很长，尾部很短

> 现会收盘于最高位附近上下两端的尾部短或根本不存在。又或者是出现没有回调的连续阳线。

**【信号2】** ⭐
- 收盘于最高位附近
- 尾部短或不存在
- 没有回调的连续阳线

> 上升微型通道K线下方有尾部。在K线快要结束时，买方大量买入。将价格推升。于是在K线底部防形成短尾。

**【信号3】** ⭐
- 上升微型通道
- K线下方有短尾（买方收盘时大量买入）

> 还有就是突破线中间存在缺口和跟进。当阳线收盘高于前面线的高位，就会形成缺口。跟进是指后续又形成一个阳线。

**【信号4】** ⭐
- 突破线中间有缺口（阳线收盘高于前高）
- 有跟进（后续又是阳线）

> 当买方压力上升时，所表现出来的就是。连续多个阳线有可能是两个，三个，四个。五个连续的阳线。同时，阳线还会越来越大，而阴线的连续数字则会减少。

**【信号5】** ⭐
- 连续多个阳线（2、3、4、5个...）
- 阳线越来越大
- 阴线连续减少

> 比如说。也许在20，30日K线以前有两三条阴线，现在则很难见到。连续两条阴线，同时阴线会越来越小。

**【信号6】** ⭐
- 以前2-3条阴线，现在很难见到连续2条
- 阴线越来越小

### 【段落3】卖方压力

> 下降趋势中的卖方压力。当你看到一个熊市趋势，你知道熊市处于主导地位。市场在下滑，你知道这是卖方的作用。你之所以对于一个图形能够清晰的判断出。熊市处于主导位置，就是因为判断到了卖方压力。

**【判断依据】** 👀
- 看到熊市趋势 → 知道卖方主导 → 因为看到了卖方压力

> 这是一个熊市处于主导地位的因素的列表，这里面每一项。都是卖方压力的一个势力。最明显的一条就是阴线多于阳线。出现连续的两条，三条，四条阴线。阴线大于阳线。阴线的主体大于阳线的主体。这就是卖方压力的明显信号。

**【卖方压力信号】** 📉

**【信号1】** ⭐
- 阴线多于阳线
- 连续2、3、4条阴线
- 阴线大于阳线
- 阴线主体大于阳线主体

> K线收盘位置接近它们的低位。开始出现下降微型通道连续出现没有回调的。五六七条阴线

**【信号2】** ⭐
- 收盘接近低位
- 下降微型通道
- 连续5、6、7条阴线无回调

> 线上方是否存在尾部？随随看K线的形成，市场不断上升。在接近收盘的位置又开始下降，于是在上方形成短尾。

**【信号3】** ⭐
- 上方有短尾（市场上升后收盘时下降）

> 在下降突破中存不存在缺口？也就是当前K线的收盘位低于前面线的低位。当前收盘位与前面的低位有一个缺口，是否有跟进？后面出现的是否也是阴线？

**【信号4】** ⭐
- 下降突破有缺口（收盘低于前低）
- 有跟进（后面也是阴线）

> 不断加大的卖方压力连续出现阴线。最近一次出现连续两次阴线是什么时候？现在又出现了连续三个四个阴线，这就说明卖方压力在加大。

**【信号5】** ⭐
- 连续阴线越来越多（从2个到3、4个）
- 卖方压力加大

> 最近十条阴线。是不是比前面的20，30之前的卖方压力更大？连续阳线已经不再出现阳线在变小。越来越多的阴线出现下降趋势，取得了主导地位。

**【信号6】** ⭐
- 最近10条阴线比之前20-30条压力更大
- 连续阳线不再出现
- 阳线变小，越来越多阴线

### 【段落4】交易区间中的压力

> 在一个交易空间当中，买方和卖方都试图形成一个突破，买方想要向上突破，卖方想要向下突破。很多时候。在交易空间形成的过程当中，你都可以去评估买方和卖方的压力大小。用来判断谁最将最终形成突破，以帮助你提前入场。

**【Al Brooks金句】** 💡⭐⭐⭐
> "评估买方和卖方的压力大小，用来判断谁最终将最终形成突破，以帮助你提前入场。"

> 洋县属于什方？图形当中的绿色部分代表的就是阳线。卖方压力越大，后续的价格就可能越低，阳线越多。买方压力越大。后续的价格可能就越高。

**【压力与价格关系】** 📊
- 卖方压力越大 → 价格可能越低
- 买方压力越大 → 价格可能越高

> 对于一个上升趋势，牛市处于主导价格应该会上升。对于一个熊市趋势，形势处于主导。价格应该会下降。

### 【段落5】永远在场 (Always In)

> 永远在场，是我做交易时常用的一个概念。什么叫永远在场呢？如果某一时刻你一定要入场。做空还是做多，你要决定买进还是卖出？你必须要做出一个选择，那么你就选择永远在场方向。

**【Always In定义】** 🎯
- 如果必须选择做多还是做空
- 选择"永远在场"的方向

> 当你面向市场时。现在还不确定。但是在20K线之前，有一个非常漂亮的。向上跳跃，所以我决定买进。此时市场就处于多头。

**【判断例子】** 📈
- 20根K线前有漂亮的向上跳跃
- 决定买进 → 市场处于多头

> 当市场处于多头说明买方的资金更雄厚。价格应该会上升，所以你应该买进。当市场处于空头。说明卖方的资金更雄厚。卖方压力更大，价格应该会下降。所以你应该卖出。

**【结论】** ✅
- 多头：买方资金雄厚 → 买进
- 空头：卖方资金雄厚 → 卖出

> 只要你确定。除了永远在场的方向，你就要沿着该方向入场。如果市场势头非常强劲或者小的回调，你就要马上行动。如果止损位很远。那把交易量控制的很小。但是一定要进场，

**【Al Brooks金句】** 💡⭐⭐⭐
> "只要你确定了永远在场的方向，你就要沿着该方向入场。"

> 一旦你对自己。判断的永远在场的方向，非常自信。那你一定要。按照该方向进场，即使交易量非常小。

**【即使交易量小也要进场】** 💪
- 确定了Always In方向
- 非常有自信 → 一定要进场
- 即使交易量非常小

**【案例转换】** 🔄

- 判断：买方失去主导，卖方掌握主动

**【观察】** 👀
- 2条阴线
- 缺口（线低位与另一条线高位之间）
- 熊市紧迫性信号

### 【段落8】交易区间中的压力判断

> 当市场处于交易区间时。基本上是水平调整，但是在交易区间当中，如果你发现更强的买方压力。那么很有可能最终形成向上的突破。如果有更强的卖方压力，那就很可能形成向下的突破。

**【Al Brooks金句】** 💡⭐⭐⭐
> "交易区间中，如果买方压力更强 → 很可能向上突破；如果卖方压力更强 → 很可能向下突破。"

> 所以，判断交易区间当中。买方卖方压力的强弱是非常重要的。

> 如果买方压力处于主导。你觉得向上突破更可能出现，虽然目前是交易区间。市场应该会处于多头永远在场的关键就在于。此时你就要决定是做多还是做空。如果你觉得买方压力大于卖方压力，那你的结论就是做多。

**【判断方法】** 🎯
- 买方压力 > 卖方压力 → Always In = 多头 → 做多
- 卖方压力 > 买方压力 → Always In = 空头 → 做空

### 【段落9】交易区间案例1

> 现在这个就是一个交易区间。在该区间内。有非常强烈的跳水，但注意看后面出现的是什么？三条连续的阳线，再看看阴线怎么样了？出现了连续六条阴线，但后续跟进的是什么呢？不是阴线。先是有阴线。一个上升的十字线阴线。

**【观察】** 👀
- 交易区间
- 强烈跳水后 → 3条连续阳线
- 6条阴线后 → 后续不是阴线（有十字线）

> 所里这里有三个连续的阳线形成的上升折线，而后面的阴线并没有达到其底部，所以熊市没有形成连续的K线系列。

**【分析】** 💡
- 3个连续阳线形成上升折线
- 后面阴线没达到底部
- 熊市没有形成连续K线系列

> 再注意看一下，这边发生了什么形态。四个连续的阳线。而且其中存在缺口这条线的低位高于前面这一条线的高位。这条线的低位比前面这条K线的高位要高，所以市场在向上攀升，虽然处在交易区间当中。但是买方的压力却在不断的蓄积，牛市逐渐掌握了主动。

**【买方压力蓄积】** 📈
- 4个连续阳线
- 存在缺口（线低位高于前高）
- 市场向上攀升
- 买方压力不断蓄积
- 牛市逐渐掌握主动

> 这是后面的形态，我们刚才在这里，在这的时候我们决定做多。小量的买入，把出场点设在最近的高位或低位处。预计市场会向上攀升，然后波段操作。

**【操作】** 🎯
- 决定做多
- 小量买入
- 止损设在最近高低位
- 预计向上，波段操作

- 买方认为这是牛市突破的回调

> 前面这里有一个低位，皆看是更高低位。更高低位，然后又是一个更高低位，这里有高位更高，高位高位更高高位，所以我们已经开始看到。更高高位和更高低位

**【趋势确认】** 📈
- 更高低位(HL)
- 更高高位(HH)
- 牛市特征

> 买方希望收盘在这个低位的上方。所以买方在这里大量买入，把止损位设在。前面更高低位的下方认为，该交易区间会变成一个上升通道。

**【买方操作】** 🎯
- 希望收盘在低位上方
- 大量买入
- 止损设在前面HL下方
- 认为会变成上升通道

> 后续发展就是这样，首先是一个内涵阳线，接着是一个正常的信号K线，这是前面突破的一个回调，注意看这里强势的尽头。连续八九条阳线，而且有几条还非常长。

**【后续】** 📈
- 内涵阳线 → 正常信号K线
- 强势上涨：连续8-9条阳线，有些很长

> 其所以前面这里是下降趋势，揭开是交易区间，但是后面没有继续向下。而是反转向上。当下降的K线比较多时，卖方压力将处于主导地位，那么向下的突破将更可能发生。市场将处于空头。所以你应该卖出。

**【总结对比】** ⚖️
- 前面：下降趋势 → 交易区间
- 后面：没有继续向下 → 反转向上
- 如果下降K线多 → 卖方主导 → 向下突破 → 卖出

### 【段落13】通道与交易区间

> 通道最后通常会变成交易区间，通常最后发展。都变成了横向发展。上升通道会有不断加强的买方压力。这其实是它很快就会变成交易区间的一个信号。

**【Al Brooks金句】** 💡⭐⭐⭐
> "上升通道会有不断加强的买方压力，这其实是它很快就会变成交易区间的一个信号。"

> 对于一个下降通道，当卖方压力不断加强时，这就是它将要变成交易区间的一个信号。

**【对称规律】** 📊
- 上升通道 + 买方压力加强 → 将变成交易区间
- 下降通道 + 卖方压力加强 → 将变成交易区间

**【演变】** 📈
- 强烈上扬 → 向上通道
- 2个长阳线 → 突破
- 2个小阳线 → 窄交易区间

> 阴线开始出现前面，这里是强烈的上升趋势。一个上升通道。随着卖方压力的增大，发展成了一个交易空间。

**【案例】** 🔄
- 强烈上升趋势 → 上升通道
- 卖方压力增大 → 发展成交易区间

### 【段落15】买方压力案例

> 这是下降趋势当中的买方压力。下降通道可以看到有更低低位，更低高位。这是一个非常强势的下降通道，但是我们有可能迎来第三波下推。

**【观察】** 👀
- 强势下降通道
- 更低低位(LL)，更低高位(LH)
- 可能有第三波下推

> 第一，第二，第二。非常有可能。形成一个反子形态，当出现双底形态时。前面这里有一个上推，这是第二个上推。所以这里是一个双底

**【形态】** 📊
- 双底形态
- 第一波上推 → 第二波上推 = 双底

> 在熊市位端形成双底的话。那么你就应该想到，在熊市位端有可能形成旗帜形态，所以这里有可能出现反转，

**【预测】** 🔮
- 熊市末端双底 → 可能形成旗帜形态 → 可能反转

> 这是双K线的反转。然后是向上的K线，所以应该买进这里，还出现了连续四条阳线。还有这个6K线的微型上升通道，6K线却完全没有回调。

**【反转确认】** ✅
- 双K线反转
- 向上K线 → 应该买进
- 连续4条阳线
- 6K线微型上升通道（无回调）

> 这里已经看到了买方家里的蓄积，熊市已经走到位端。卖方把它看作是下降的旗帜形态，但是它没有形成向上的突破，而是向上形成了突破。

**【买方压力蓄积】** 📈
- 买方压力蓄积
- 熊市走到末端
- 卖方以为是下降旗帜
- 但实际上向上突破

> 所以比较激进的买方会在这一条线收盘时买进。在该线形成时，也会买进把止损位放在其下方，认为突破最终会向上形成。

**【操作】** 🎯
- 激进买方：线收盘时买进
- 止损：线下方
- 认为：突破最终会向上

> 根据旗帜形态的判断。市场应该急速向上，第一个目标。就是该通道的上边缘。结果就是这样，非常强势的一波上扬。

**【结果】** 🚀
- 旗帜形态 → 应该急速向上
- 第一目标：通道上边缘
- 结果：非常强势上扬

> 上面很小的尾巴，收盘离高位很近，买方会在收盘处买进，把止损位设置在。突破K线低位的下方。或者在该上扬开始低位的下方。

**【买方操作】** 💪
- 收盘离高位很近，小尾巴
- 买方收盘处买进
- 止损：突破K线低位下方 或 上扬开始低位下方

> 所以在该熊市的位端，我们看到了买方压力的出现。最终形成了向上的反转，后续的发展就是这样。

### 【段落16】总结

> 买方在收盘时大量买进非常强烈的上扬，交易员都把这一波走势看作了上升趋势。虽然在这里出现了回调，而且后续很可能就变成了交易区间。但这是在前面强烈的上扬之后所形成的一个上扬通道。

**【总结】** 📊
- 买方收盘时大量买进
- 强烈上扬
- 交易员看作上升趋势
- 虽然有回调，可能变交易区间
- 但：强烈上扬后的上扬通道

> 所以后面很有可能是价格不断攀升。所以交易员肯定是买进止损位，有可能在这个下方，也可能在缺口这里。

> 该线的低位。高于前面极致形态的高位，所以在这里形成了缺口。这就是一个突破缺口，这可能是一个测量缺口。非常长的阳线。

**【缺口类型】** 📈
- 突破缺口
- 可能是测量缺口
- 非常长的阳线

## 🎴 学习卡片

### 卡片1
**什么是买方压力？有哪些主要信号？**
:: 买方压力是倾向于牛市的价格行为。主要信号：阳线多于/大于阴线、阳线连续、收盘于最高位附近、上升微型通道、突破缺口+跟进、阳线越来越大而阴线越来越小。

### 卡片2
**什么是卖方压力？有哪些主要信号？**
:: 卖方压力是倾向于熊市的价格行为。主要信号：阴线多于/大于阳线、阴线连续、收盘接近低位、下降微型通道、下降缺口+跟进、连续阴线越来越多而阳线不再出现。

### 卡片3
**什么是"永远在场"(Always In)？如何应用？**
:: 如果必须选择做多还是做空，选择压力主导的方向。买方压力主导→Always In Long→买进；卖方压力主导→Always In Short→卖出。即使交易量很小，也要进场。

### 卡片4
**为什么在交易区间中可以提前入场，不需要等待突破？**
:: 通过评估买方和卖方压力强弱，可以判断谁最终将形成突破。如果买方压力更强，很可能向上突破，可以提前做多；反之亦然。

### 卡片5
**通道什么时候会变成交易区间？有什么信号？**
:: 上升通道中买方压力不断加强，或下降通道中卖方压力不断加强，都是即将变成交易区间的信号。通道通常会是交易区间的开始。

### 卡片6
**如何判断市场周期的压力转换？举例说明。**
:: 观察连续K线的变化。比如前面是强烈下降通道（卖方压力），但后面出现：连续阳线、阳线之间有缺口、K线底部有短尾、形成双底等，这些都是买方压力蓄积、可能反转的信号。
