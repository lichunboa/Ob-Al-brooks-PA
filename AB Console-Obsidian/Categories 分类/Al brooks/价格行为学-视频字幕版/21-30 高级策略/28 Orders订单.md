# 28 Orders订单

> **Al Brooks**: "订单是你的武器，选错武器，再好的战士也会败北。"

---

## 📖 原文逐段解析

### 【段落1】订单类型概述

> 这一讲，我们来讲订单。对手入场订单初，学者只应该考虑止损价入场。这样趋势发展会自动使订单生效，随看趋势顺势入场。

**【三种订单类型】** 

| 订单类型 | 适用场景 | 难度 |
|---------|---------|------|
| 止损单（Stop Order） | 趋势明确，突破交易 | 中等 |
| 限价单（Limit Order） | 交易区间，突破失败 | 高 |
| 市价单（Market Order） | 强劲突破，紧急入场 | 高 |

**【初学者建议】**
> "初学者只应该考虑止损价入场，这样趋势发展会自动使订单生效，随着趋势顺势入场。"

> 💡 **Al Brooks金句**: "止损单是初学者的训练轮，限价单是成手的特技。"

---

### 【段落2】止损单入场

> 如何操作止损架入场呢？在前面K线的突破位买进或者卖出。对于波动或者趋势，这种方法常有效。

**【止损单定义】**
> "止损单是指在价格突破某一水平时自动生效的订单，用于顺势入场。"

**【操作方法】**
```
买入止损单：
- 设置在前一K线高位上方
- 市场突破时自动买入
- 顺势做多

卖出止损单：
- 设置在前一K线低位下方
- 市场突破时自动卖出
- 顺势做空
```

**【适用条件】**
- 趋势明确
- 波动较大
- K线重叠小
- 连续趋势K线

**【不适用场景】**
- 水平发展
- 窄交易区间
- 大量影线

> 💡 **Al Brooks金句**: "止损单是顺势的门票，逆势时别用它。"

---

### 【段落3】限价单入场

> 当使用限价订单入场时，是在最近一个点位处相反的方向入场。比如，通过限价订单买进，那就是在市场下跌时买进。

**【限价单定义】**
> "限价单是指在特定价格或更好价格执行的订单，用于逆势入场（预期反转）。"

**【操作方法】**
```
买入限价单：
- 设置在前一K线低位下方
- 市场下跌时买入
- 预期反转向上

卖出限价单：
- 设置在前一K线高位上方
- 市场上涨时卖出
- 预期反转向下
```

**【本质】**
- 逆势操作
- 判断突破会失败
- 需要高技巧

> 💡 **Al Brooks金句**: "限价单是逆势的赌注，赌的是突破的虚假。"

---

### 【段落4】突破成功 vs 突破失败

> 止损价入场判断突破会成功，限价订单入场判断突破会失败。

**【判断标准】**

**突破会成功（止损单）：**
- 大波动
- K线重叠小
- 连续趋势K线
- 强劲趋势

**突破会失败（限价单）：**
- 水平发展
- 大量影线
- 交易区间
- 弱趋势

**【K线形态判断】**
```
适合止损单：
- 连续阳线/阴线
- 实体长，影线短
- 收盘在极端位置

适合限价单：
- 大量十字星
- 影线长，实体短
- 阴阳交替
```

> 💡 **Al Brooks金句**: "影线是突破失败的预告，实体是突破成功的证明。"

---

### 【段落5】交易区间中的限价单

> 当市场处在交易区间的顶部、底部时，突破大多数会失败。

**【交易区间限价单策略】**

**区间顶部：**
- 出现弱买入信号
- 在前高上方设限价卖单
- 判断突破失败

**区间底部：**
- 出现弱卖出信号
- 在前低下方设限价买单
- 判断突破失败

**【示例】**
```
交易区间顶部：
- 市场上涨至区间顶
- 出现十字线（弱信号）
- 在前高上方设限价卖单
- 突破失败 → 卖单激活 → 做空

交易区间底部：
- 市场下跌至区间底
- 出现十字线（弱信号）
- 在前低下方设限价买单
- 突破失败 → 买单激活 → 做多
```

> 💡 **Al Brooks金句**: "交易区间的边缘是限价单的乐园，中间是止损单的陷阱。"

---

### 【段落6】市价单入场

> 对于这一段上升放量配线，或这段上升放量K线，可以做市场价买单。

**【市价单定义】**
> "市价单是指以当前市场价格立即执行的订单，用于紧急入场。"

**【适用场景】**
- 强劲突破
- 不想错过机会
- 趋势明确
- 时间紧迫

**【风险】**
- 止损距离远
- 滑点可能大
- 需要快速决策

**【小周期辅助】**
```
大周期（5分钟）：
- 出现突破
- 但K线已很长
- 止损距离远

转到小周期（1分钟）：
- 寻找早期入场点
- 止损更近
- 或等待回调
```

> 💡 **Al Brooks金句**: "市价单是紧急刹车，用多了会磨损轮胎。"

---

### 【段落7】信号K线与入场K线

> 该线就是信号K线。如果最终激活入场，入场时对应的K线就是你的场K线。

**【概念区分】**

| 概念 | 定义 | 作用 |
|-----|------|------|
| 信号K线 | 触发交易决策的K线 | 确定方向和止损 |
| 入场K线 | 实际执行交易的K线 | 确定入场点 |

**【止损设置】**
```
买入：
- 信号K线低位下方
- 入场K线低位下方
- 或固定点数

卖出：
- 信号K线高位上方
- 入场K线高位上方
- 或固定点数
```

**【目标设置】**
- 最小：等于风险
- 理想：2×风险
- 测量距离法

> 💡 **Al Brooks金句**: "信号K线是灯塔，入场K线是登船，两者不一定在同一码头。"

---

### 【段落8】等待第二信号

> 如果想要通过止损单入场，等待第二个或第三个信号。然后再考虑入场。

**【为什么等待第二信号】**
- 第一信号可能假突破
- 第二信号更可靠
- 增加成功概率

**【示例】**
```
第一信号：
- 强劲突破
- 但犹豫未入场
- 市场回调

第二信号：
- 再次向上突破
- 更可靠
- 入场
```

**【不确定时不入场】**
> "只要不确定，就不要入场。"

> 💡 **Al Brooks金句**: "等待第二信号是耐心的回报，着急入场是冲动的代价。"

---

### 【段落9】订单选择总结

> 订单这一章节到此结束。

**【选择决策树】**
```
市场状态
    ├── 强劲趋势 + 大波动
    │       ├── 初学者 → 止损单
    │       └── 成手 → 市价单或止损单
    │
    ├── 交易区间 + 大量影线
    │       ├── 初学者 → 观望
    │       └── 成手 → 限价单
    │
    └── 不确定
            └── 等待第二信号
```

**【风险收益考虑】**
- 止损单：顺势，风险明确
- 限价单：逆势，需要技巧
- 市价单：紧急，风险较大

> 💡 **Al Brooks金句**: "订单选择是交易的第一道门，选对了门，路就好走。"

## 🧠 核心知识卡片

### 卡片1：三种订单类型

```yaml
止损单 (Stop Order):
  定义: 价格突破某一水平时自动生效的订单
  方向: 顺势
  操作:
    买入: 设置在前一K线高位上方
    卖出: 设置在前一K线低位下方
  适用:
    - 趋势明确
    - 波动大
    - K线重叠小
    - 连续趋势K线
  不适用:
    - 水平发展
    - 窄交易区间
    - 大量影线
  适用人群: 初学者首选

限价单 (Limit Order):
  定义: 在特定价格或更好价格执行的订单
  方向: 逆势（预期反转）
  操作:
    买入: 设置在前一K线低位下方（下跌时买入）
    卖出: 设置在前一K线高位上方（上涨时卖出）
  适用:
    - 交易区间
    - 突破失败预期
    - 大量影线
  不适用:
    - 强劲趋势
    - 大波动
  适用人群: 有经验的交易员

市价单 (Market Order):
  定义: 以当前市场价格立即执行的订单
  方向: 顺势
  操作: 立即执行
  适用:
    - 强劲突破
    - 紧急入场
    - 不想错过机会
  风险:
    - 止损距离远
    - 滑点可能大
    - 需要快速决策
  适用人群: 有经验的交易员
```

### 卡片2：突破成功 vs 突破失败

```yaml
突破会成功（止损单）:
  特征:
    - 大波动
    - K线重叠小
    - 连续趋势K线
    - 实体长，影线短
    - 收盘在极端位置
  
  K线形态:
    - 连续阳线/阴线
    - 强劲趋势K线
    - 几乎没有回调

突破会失败（限价单）:
  特征:
    - 水平发展
    - 大量影线
    - 交易区间
    - 影线长，实体短
    - 阴阳交替
  
  K线形态:
    - 大量十字星
    - 长影线K线
    - 频繁反转

判断要点:
  - 看K线重叠程度
  - 看影线与实体比例
  - 看趋势强度
  - 看所处位置（趋势/区间）
```

### 卡片3：交易区间中的限价单策略

```yaml
区间顶部:
  条件:
    - 市场上涨至区间顶
    - 出现弱买入信号（十字线等）
  
  操作:
    - 在前高上方设限价卖单
    - 判断突破失败
    - 做空

区间底部:
  条件:
    - 市场下跌至区间底
    - 出现弱卖出信号（十字线等）
  
  操作:
    - 在前低下方设限价买单
    - 判断突破失败
    - 做多

关键:
  - 确认交易区间
  - 识别弱信号
  - 耐心等待突破尝试
  - 快速止损（如果突破成功）

不适用:
  - 强劲趋势中
  - 区间中间位置
  - 信号不明确时
```

### 卡片4：信号K线与入场K线

```yaml
信号K线:
  定义: 触发交易决策的K线
  作用:
    - 确定交易方向
    - 设置止损位
    - 评估风险

入场K线:
  定义: 实际执行交易的K线
  作用:
    - 确定实际入场点
    - 可能与信号K线不同

关系:
  止损单:
    - 信号K线 = 前一K线
    - 入场K线 = 突破K线（下一K线）
  
  限价单:
    - 信号K线 = 参考K线
    - 入场K线 = 触及限价位的K线

止损设置:
  买入:
    - 信号K线低位下方
    - 或入场K线低位下方
  
  卖出:
    - 信号K线高位上方
    - 或入场K线高位上方

目标设置:
  - 最小: 等于风险
  - 理想: 2×风险
  - 使用测量距离法
```

### 卡片5：订单选择决策树

```yaml
决策流程:
  第一步: 判断市场状态
    - 强劲趋势？
    - 交易区间？
    - 不确定？
  
  第二步: 选择订单类型
    强劲趋势:
      - 初学者 → 止损单
      - 成手 → 市价单或止损单
    
    交易区间:
      - 初学者 → 观望
      - 成手 → 限价单
    
    不确定:
      - 等待第二信号
      - 或不交易
  
  第三步: 设置参数
    - 确定止损位
    - 计算风险
    - 设置目标位
    - 验证交易公式

关键原则:
  - 初学者只用止损单
  - 限价单只在交易区间用
  - 市价单只在紧急时用
  - 不确定时等待
```

### 卡片6：订单交易Checklist

```yaml
交易前分析:
  □ 判断市场状态（趋势/区间/不确定）
  □ 评估波动和K线形态
  □ 确定突破可能性
  □ 选择合适订单类型

止损单检查:
  □ 趋势是否明确？
  □ 波动是否足够？
  □ K线重叠是否小？
  □ 止损位设置合理？

限价单检查（成手）:
  □ 是否在交易区间？
  □ 是否有大量影线？
  □ 信号是否弱？
  □ 突破是否可能失败？

市价单检查（成手）:
  □ 是否强劲突破？
  □ 是否时间紧迫？
  □ 是否能接受远止损？
  □ 是否快速决策？

信号确认:
  □ 是否等待第二信号？
  □ 信号K线是否清晰？
  □ 入场K线是否确定？
  □ 止损位是否明确？

风险管理:
  □ 风险是否可承受？
  □ 目标是否≥风险？
  □ 交易公式是否满足？
  □ 不确定时是否观望？

每日复盘:
  □ 订单类型选择是否正确？
  □ 止损设置是否合理？
  □ 是否应该等待第二信号？
  □ 限价单使用是否恰当？
```
