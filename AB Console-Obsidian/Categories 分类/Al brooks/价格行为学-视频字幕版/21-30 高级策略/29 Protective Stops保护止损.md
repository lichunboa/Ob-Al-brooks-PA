# 29 Protective Stops保护止损

> **Al Brooks**: "止损是你的安全气囊，不是方向盘——它保护你不撞死，但不替你开车。"

---

## 📖 原文逐段解析

### 【段落1】止损的意义

> 正损位的意义是什么呢？它是针对你的操作进行保护，而并不是针对市场情绪，最终可以影响你的决策。如果没有止损的操作，有时候你会放任损失的增加。

**【止损的核心作用】**
> "止损是针对你的操作进行保护，防止损失无限增加，而不是针对市场情绪。"

**【没有止损的危险】**
- 放任损失增加
- 一次大亏抵消多次小赚
- 情绪影响决策

**【止损的心理作用】**
- 明确最大损失
- 保持客观性
- 避免情绪化决策

> 💡 **Al Brooks金句**: "没有止损的交易就像没有刹车的车，速度快了就会失控。"

---

### 【段落2】止损金额的控制

> 首先，你必须确认存在风险的金额是你能够轻松容忍的。不管是哪个金额。一定不要设置超过你能够承受的金额的风险。

**【风险承受原则】**
> "止损金额必须是你能够轻松承受的，超过承受范围会导致情绪失控。"

**【大止损的处理】**
```
止损是平时的3倍 → 仓位减至1/3
止损是平时的4倍 → 仓位减至1/4

目标：保持潜在风险金额恒定
```

**【为什么控制仓位】**
- 避免过度紧张
- 保持操作客观性
- 防止情绪影响

> 💡 **Al Brooks金句**: "大止损配小仓位，小止损配大仓位——风险金额不变，心态才能稳。"

---

### 【段落3】趋势中的止损移动

> 对于上升趋势，走势中有更高高位和更高低位。它包含于上升通道当中。上升通道的底部就是上升趋势线。

**【上升趋势止损移动】**
```
规则：
- 市场创新高 → 止损移至最近更高低位下方
- 市场不再创新高/新低 → 趋势可能结束，考虑出场

示例：
买入 → 市场涨至105 → 止损从95移至100（最近更高低位下方）
     → 市场涨至110 → 止损从100移至105
```

**【下降趋势止损移动】**
```
规则：
- 市场创新低 → 止损移至最近更低高位上方
- 市场不再创新低/新高 → 趋势可能结束，考虑出场
```

**【趋势结束信号】**
- 不再创新高/低
- 跌破最近更高低位（上升）
- 突破最近更低高位（下降）
- 进入交易区间

> 💡 **Al Brooks金句**: "止损跟着趋势走，趋势停了你也要停。"

---

### 【段落4】主动止损 vs 被动止损

> 当你发现市场跟你的预判出现了反差，你觉得入场时的判断已经不对了。不要等待被迫止损离场。

**【主动止损】**
> "当发现市场与预判出现反差，判断已经错误时，不要等待被迫止损，应立即主动离场。"

**【何时主动止损】**
- 市场方向改变
- 预判被证伪
- 出现相反信号
- 永远在场状态改变

**【示例】**
```
预判：永远在场多头
现实：市场进入永远在场空头
行动：立即主动止损，不要等待
```

**【被动止损的作用】**
- 防止意外（电脑崩溃、突发电话等）
- 避免情绪干扰
- 最后防线

> 💡 **Al Brooks金句**: "主动止损是清醒时的决断，被动止损是昏迷时的保险。"

---

### 【段落5】止损位的三种选择

> 对于安全止损位有三个选择。价格行为止损，如超过信号线处。有时候也可以选择金额止损，距离入场点一定的点数。另外，止损位也可以根据测量距离来设定。

**【三种止损类型】**

| 类型 | 定义 | 适用场景 |
|-----|------|---------|
| 价格行为止损 | 信号K线极值外侧 | 大多数交易 |
| 固定金额止损 | 固定点数（如10点） | 快速决策 |
| 测量距离止损 | 基于形态高度 | 不确定时 |

**【价格行为止损】**
```
买入：信号K线低位下方
卖出：信号K线高位上方

信号K线过大时：
- 可选中间位
- 或固定金额
```

**【固定金额止损】**
```
示例：
- 10点
- 20点
- 日均波动的10-20%
```

**【测量距离止损】**
```
基于：
- 信号K线高度
- 缺口高度
- 目标收益距离
```

> 💡 **Al Brooks金句**: "止损位是你的安全网，网太大你会掉下去，网太小你会被缠住。"

---

### 【段落6】初始风险 vs 实际风险

> 初始止损位就是你初始的风险。这也决定了你初始的最低目标位。收益目标不能小于你的初始风险。

**【初始风险】**
- 入场时设定的止损距离
- 决定初始目标位
- 目标 ≥ 初始风险

**【实际风险】**
- 市场实际反向发展的距离
- 通常小于初始风险
- 可据此调整目标位

**【调整目标位】**
```
初始风险：5点 → 目标10点（2×）
实际风险：3点 → 可调整目标为6点（2×）

或保持目标10点（更大利润）
```

**【实际风险的应用】**
- 交易区间常见
- 信号K线特别长时
- 更现实的目标设定

> 💡 **Al Brooks金句**: "初始风险是计划，实际风险是现实——计划要远大，现实要灵活。"

---

### 【段落7】远距离止损

> 有些人喜欢把止损位设的非常远，比如根据交易区间获得的测量距离。他们的想法是这样。只称为永远不会被打倒。

**【远距离止损的目的】**
- 防止意外（崩盘、数据错误等）
- 给足够时间判断
- 避免频繁止损

**【远距离止损的取舍】**
```
优点：
- 成功概率更高
- 不被噪音扫出
- 有时间思考

缺点：
- 单次损失更大
- 需要小仓位
- 心理压力大
```

**【远距离止损的使用】**
- 仓位减小（1/3或1/4）
- 保持风险金额恒定
- 通常提前主动出场
- 不作为实际出场点

> 💡 **Al Brooks金句**: "远距离止损是防意外的安全气囊，不是让你撞墙的借口。"

---

### 【段落8】盈亏平衡止损

> 假设你在上升趋势中买进很多交易员。会等待市场向上发展一段距离之后，允许市场下滑一次，此时仍然相信初始止损位。但是当市场又开始继续上升趋势时候，他们就会把止损位移动到盈亏箱底处。

**【盈亏平衡止损】**
> "当市场沿预期方向发展后，将止损移至入场点附近，保护本金。"

**【操作流程】**
```
1. 入场并设置初始止损
2. 市场沿预期发展
3. 出现回调但不触及止损
4. 市场再次沿预期发展
5. 将止损移至盈亏平衡（入场点附近）
6. 继续移动止损跟随趋势
```

**【意义】**
- 保护本金
- 心理安全感
- 允许持仓更久

**【注意事项】**
- 不要太早移动（给市场空间）
- 确认趋势继续后再移
- 避免被小幅回调扫出

> 💡 **Al Brooks金句**: "盈亏平衡是交易的转折点，之前是冒险，之后是赚多赚少。"

---

### 【段落9】止损调整总结

> 安全止损位可以保证你自己不犯错误。但是不要以为他们永远不会被达到止损位，经常会被达到。

**【止损调整原则】**

**趋势中：**
- 创新高/低 → 移动止损
- 跟随最近高低点
- 或跟随趋势线
- 或固定金额

**交易区间中：**
- 不要远距离止损
- 区间顶部卖出
- 区间底部买入
- 短线操作

**盈亏平衡：**
- 趋势发展后移动
- 保护本金
- 然后让利润奔跑

**主动 vs 被动：**
- 判断错误 → 主动止损
- 意外情况 → 被动止损保护

> 💡 **Al Brooks金句**: "止损是你的保镖，你要听他的，但不要完全依赖他。"

descending趋势:

    跌至90 → 止损移至95
  
  趋势结束信号:
    - 不再创新低
    - 突破最近更低高位
    - 进入交易区间

### 卡片3：主动止损 vs 被动止损

```yaml
主动止损:
  定义: 发现判断错误时立即出场
  
  触发条件:
    - 市场方向改变
    - 预判被证伪
    - 出现相反信号
    - 永远在场状态改变
  
  示例:
    预判: 永远在场多头
    现实: 进入永远在场空头
    行动: 立即主动止损

    - 减少损失
    - 保持清醒

被动止损:
  定义: 等待止损位被触及
  
  作用:

    - 避免情绪干扰
    - 最后防线
  
  使用:
    - 意外情况
    - 无法盯盘时
    - 作为保险

关系:
  - 优先主动止损
  - 被动止损是底线
  - 两者结合使用
```

### 卡片4：三种止损类型

```yaml
价格行为止损:
  定义: 基于信号K线极值
  
  设置:
    买入: 信号K线低位下方
    卖出: 信号K线高位上方
  
  信号K线过大时:
    - 选中间位
    - 或固定金额
  
  适用: 大多数交易

固定金额止损:
  定义: 固定点数止损
  
  示例:
    - 10点
    - 20点
    - 日均波动10-20%
  
  适用:
    - 快速决策
    - 信号K线过大
    - 不想复杂计算

测量距离止损:
  定义: 基于形态高度
  
  基准:
    - 信号K线高度
    - 缺口高度
    - 目标收益距离
  
  适用:
    - 不确定时
    - 需要更宽松止损
    - 大形态交易

选择:
  - 根据形态选择
  - 根据时间周期选择
  - 根据个人风格选择
```

### 卡片5：初始风险 vs 实际风险

```yaml
初始风险:
  定义: 入场时设定的止损距离
  
  作用:
    - 决定初始目标位
    - 评估交易价值
    - 初始仓位计算
  
  目标设置:
    目标 ≥ 初始风险
    理想: 2×初始风险

实际风险:
  定义: 市场实际反向发展的距离
  
  特点:
    - 通常小于初始风险
    - 动态变化
    - 更现实
  
  应用:
    - 调整目标位
    - 交易区间常见
    - 信号K线过长时

调整示例:
  初始:
    风险5点 → 目标10点（2×）
  
  实际:
    风险3点 → 可调整目标6点（2×）
    或保持10点（更大利润）

使用:
  - 初始风险定计划
  - 实际风险调策略
  - 两者结合优化
```

### 卡片6：止损交易Checklist

```yaml
交易前:
  □ 确定止损类型（价格行为/固定金额/测量距离）
  □ 计算初始风险
  □ 确认风险可承受
  □ 大止损则减小仓位
  □ 目标 ≥ 风险

入场后:
  □ 设置初始止损
  □ 观察市场发展
  □ 判断是否正确
  
  趋势发展:
    □ 创新高/低 → 移动止损
    □ 移至最近高低点外侧
    □ 或移至盈亏平衡
    □ 继续跟随趋势
  
  判断错误:
    □ 立即主动止损
    □ 不等待被动止损
    □ 重新评估

交易区间:
  □ 不使用远距离止损
  □ 区间顶部卖出
  □ 区间底部买入
  □ 短线操作

每日复盘:
  □ 止损是否被合理触及？
  □ 是否应该主动止损？
  □ 止损位设置是否合理？
  □ 是否及时调整止损？

常见错误:
  ✗ 无止损交易
  ✗ 止损过大（仓位未减）
  ✗ 该主动止损时不行动
  ✗ 交易区间用趋势止损
  ✗ 过早移动至盈亏平衡
```
