## 🚀 使用方法

**Windows**:
```bash
# 双击图标

```

### Docker 故障时

**不要寻找替代方案，必须修复 Docker**:

1. **重启 Docker Desktop**
   ```bash
   killall Docker
   sleep 10
   open /Applications/Docker.app
   ```

2. **使用修复脚本**
   ```bash
   ./📁\ 启动工具/🔧\ 修复并启动Docker.sh
   ```

3. **重置 Docker Desktop** (如果重启无效)
   - Docker Desktop → Settings → Troubleshoot → Clean/Purge data

4. **重新安装 Docker Desktop** (如果重置无效)
   - 从官网下载: https://www.docker.com/products/docker-desktop
