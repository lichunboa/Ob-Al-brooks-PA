## 🔧 Docker 修复指南

### 自动修复
运行 `🔧 修复并启动Docker.sh`，脚本会自动:
1. 检查 Docker Desktop 状态
2. 清理未使用的资源
3. 启动核心服务
4. 验证服务状态

### 手动修复
如果自动修复失败:
```bash
# 1. 完全退出 Docker
killall Docker

# 2. 等待 10 秒

# 3. 重新启动
open /Applications/Docker.app

# 4. 验证
docker ps
```
