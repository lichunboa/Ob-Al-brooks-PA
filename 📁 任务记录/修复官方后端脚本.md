# 修复 TradeCat 官方后端脚本（macOS 兼容）

## 问题
官方 `./scripts/start.sh` 在 macOS 上有兼容性问题：
- `grep -P` 不支持
- 权限检查变量错误

## 修复步骤

### 1. 修复 grep -P 问题
```bash
cd "/Users/mitchellcb/Desktop/Obsidian/Al-brooks-PA/AB Console-Backend"

# 备份原脚本
cp scripts/start.sh scripts/start.sh.backup

# 替换 grep -P 为 grep -E（macOS 兼容）
sed -i '' 's/grep -P/grep -E/g' scripts/start.sh

# 修复权限检查变量
sed -i '' 's/perm\x00/perm/g' scripts/start.sh
```

### 2. 使用 Python 直接启动（绕过脚本问题）
```bash
# 1. 启动 TimescaleDB
docker run -d --name tradecat-timescaledb \
  -p 5434:5432 \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=market_data \
  timescale/timescaledb:latest-pg16

# 2. 等待数据库就绪
sleep 10

# 3. 启动 data-service
cd services/data-service
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 -m src --all &

# 4. 启动 trading-service
cd ../trading-service
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 -m src --full &

# 5. 启动 signal-service
cd ../signal-service
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 -m src --all &

# 6. 启动 api-service（预览版，提供 REST API）
cd ../services-preview/api-service
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 -m src &
```
