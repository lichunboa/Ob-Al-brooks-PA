## 概念诊断逻辑

每笔交易平仓后，不问"赚了还是亏了"，而问：
1. AI方向判断对了吗？→ 测试 `always_in` 概念
2. 市场状态识别对了吗？→ 策略与状态是否匹配
3. 入场形态选择对了吗？→ 顺势还是反转，时机对不对
4. 信号K线质量够吗？→ 是不是勉强入场
5. 盈亏比合理吗？→ 交易者方程是否成立
6. 大周期背景一致吗？→ 有没有逆势硬扛

弱项 → 下次遇到该概念时更保守（扣分）
强项 → 更果断（加分）

## 交易哲学 (Al Brooks)

- **"Context > 形态 > 信号K线"** — 先理解环境，再看形态，最后看那根K线
- **"80% 的时间市场在震荡"** — 不确定就是交易区间
- **"好的亏损是执行正确但概率不在我这边"** — 过程正确比结果重要
- **"让利润奔跑 — 交易者方程永远比感觉重要"** — 数学不骗人
