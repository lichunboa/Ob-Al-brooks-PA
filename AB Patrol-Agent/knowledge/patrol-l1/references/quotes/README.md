# Q Files（纪律锚点层）

`Q` 文件不是新的策略层，也不是新的知识库。

它们只负责 3 件事：

1. 用 Al Brooks 原话校正 agent 的行为偏差
2. 在关键阶段提醒 `Context > 形态 > 信号K线`
3. 防止因为恐惧、追求完美、过早保本、混淆 scalp/swing 而错过本来应该做的交易

## 与 SKILL / S / C 的关系

- `C`：理论规范层，回答“Al Brooks 整体上怎么定义这件事”
- `SKILL`：流程层，回答“这一轮先做什么、再做什么”
- `S`：可执行规则层，回答“这个 setup 怎么判、怎么做、怎么管理”
- `Q`：纪律锚点层，回答“当 agent 犹豫、过度保守、过度追求完美时，应该用哪条 Al Brooks 原话纠偏”

## 何时加载

运行时不会每轮全部加载 `Q1-Q6`。

当前路由原则：

- `Q1-context`
  - 配合 `S1/S2/S3/S3b`
- `Q2-direction`
  - 配合 `S2/S4/S6`
- `Q3-fear`
  - 配合 `S4/S5/S6`
- `Q4-entry`
  - 配合 `S5/S6`
- `Q5-te`
  - 配合 `S5`
- `Q6-management`
  - 配合 `S7`

## 约束

- `Q` 文件不能取代 `S` 文件做交易规则定义
- `Q` 文件不能单独决定开仓
- `Q` 文件只能做纪律与偏差修正，不能越权成为新的 playbook
