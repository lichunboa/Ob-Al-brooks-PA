## 真空效应 (Vacuum Effect) — 磁力核心机制

**磁力基本定律**：
- 市场被 S/R（磁体）吸引 → **越接近，移动越快**
- **到达后磁力消失** → 反转/BO/TR 三种可能
- 多个 S/R 重合 = 强磁力 → 高概率反转区

**TR 内的真空动力学**：
1. 接近支撑 → 多空双方都看到 → 机构认为会下探测试
2. **多头停止买入**（等更低价）+ **空头也等待** → 卖方失衡
3. 没人买 → 大阴线 → 市场被"吸"向支撑
4. 到达磁体 → 磁力消失 → **强大买方突然出现**
5. 空头获利了结 + 多头进入 → **反转向上**
6. → 接近阻力时完全相反

**初学者因磁力亏钱**：看到动能 → 追 BO → 不理解是接近 S/R 的真空加速 → 高买低卖

### 真空加速区量化

- **≤25% 规则**：当价格距离目标 S/R 的剩余距离 < 整段运动的 25% 时，进入**真空加速区**
  - 例：从 100 涨到 120，目标磁体在 125 → 距离 5 = 总运动 25 的 20% → 已进入加速区
- **加速区特征**：K 线变大、影线消失、动能看起来最强
- **陷阱**：加速区的动能是**假信号** → 不是趋势加速，是磁力吸引
- **操作**：
  - 进入 25% 区域后 **禁止追进新仓** → 高概率到达后反转
  - 已持仓 → 准备止盈或移 SL
  - 如果在该区域看到"BO"→ 大概率是接近 S/R 的最后冲刺，不是真 BO

## 趋势中的 S/R

- 强趋势 **80% 不会在第一个 S/R 位停止**
- 反转尝试会在 S/R 失败 → 成为旗形
- **趋势中不在第一个 S/R 反转，在 S/R 位顺势获利了结**

## 止损位 = 磁体

- PB 被吸向止损位是正常的，不代表趋势结束
- 空头多次尝试到达止损位 → 失败 → 形成 Micro DB/HL

## 整数价位

- 交易者常在整数设止损和止盈 → 整数 = 磁体
- BTC 的 50000, 60000, 100000 等也有磁力

## 关键位置的 4 层作用

### 1. 磁力（吸引价格）
- 多个 S/R 重合 = 强磁力 → 高概率反转区
- **不要把接近 S/R 的加速当成趋势 BO**

### 2. 入场过滤
- TP 目标处有强 S/R 挡着 → R 缩小 → P×R 可能不达标 → 不做
- 例：做多 TP=2R，但 1.5R 处有前日 High → 实际 R 只有 1.5 → 重新评估

### 3. 定义市场结构
- TR 的上下边界就是 S/R
- 通道线本身就是 S/R
- Daily 的 HH/HL/LH/LL 定义 AI 方向

### 4. SL/TP 定价
- **SL**: 放在关键位置的另一侧（Major HL/LH 下方/上方）
- **TP**: 对准最近的磁体（MM > 前高/低 > EMA > 整数）
- **趋势中**: 80% 不在第一个 S/R 停 → 不提前止盈
- **TR 中**: S/R 几乎总有效 → 在 S/R 处止盈

---

## 评估中的 S/R 过滤（下单前必检）

1. **TP 路径上有没有强 S/R？**
   - 有 → 实际 R 缩小 → 重新算 P×R
   - 多个 S/R 重合在 TP 前 → 大概率到不了 → 降为 Scalp 或不做

2. **SL 在关键位置的正确一侧吗？**
   - SL 在 S/R 内侧 → 容易被磁力吸到 → 太近
   - SL 在 S/R 外侧 → 正确（需 BO 才能打到）

3. **价格在 TR 的哪个 1/3？**
   - 底部 1/3 → 60% 先涨 → 偏多
   - 中间 1/3 → 50/50 → 不做
   - 顶部 1/3 → 60% 先跌 → 偏空
