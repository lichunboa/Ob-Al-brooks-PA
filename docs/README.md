# AB Console - 文档中心

> 更新于 2026-02-06

## 项目概览

AB Console 是一个 Al Brooks 价格行为交易系统，包含：

- **Obsidian 知识库** — 课程笔记、策略管理、复盘分析、间隔复习
- **后端服务** — 数据采集、技术指标计算、信号检测
- **Web Dashboard** — 实时图表、市场扫描
