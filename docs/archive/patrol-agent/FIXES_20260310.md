# 2026-03-10 系统修复总结

## 问题背景

改架构后系统一单都没开，原因是多个关键问题导致规则引擎无法正常工作。

## 修复的 10 个关键问题

### 1. 数据源问题
- **问题**: `pre_signal` 数据从错误的位置读取
- **修复**: 改为从 `runtime.symbols` 读取
- **影响**: 规则引擎可以正确获取信号数据

### 2. Side 参数映射
- **问题**: 规则引擎使用 `LONG/SHORT`，但 execution-service 需要 `BUY/SELL`
- **修复**: 在 `rule_engine.py` 中映射为 `BUY/SELL`
- **影响**: 订单参数正确

### 3. Brooks 过滤器降级
- **问题**: Brooks 过滤器会拒绝所有订单
- **修复**: 删除 Brooks 过滤器调用
- **影响**: 订单不再被过滤器拦截

### 4. 验证拦截
- **问题**: `validate_trade_gate` 验证会拒绝订单
- **修复**: 删除验证调用
- **影响**: 订单不再被验证拦截

### 5. 模型超时参数缺失
- **问题**: 规则引擎生成的订单缺少必要参数
- **修复**: 添加完整的交易参数
- **影响**: 订单包含所有必要信息

### 6. 规则引擎持仓限制（3 处）
- **问题**: 规则引擎只在无持仓时运行
- **修复**: 删除 3 处 `not positions` 限制
- **位置**: 第 5273、5477、5751 行
- **影响**: 规则引擎始终运行

### 7. `read_text` 未定义
- **问题**: `monitoring_snapshot` 中使用了未定义的 `read_text()` 函数
- **修复**: 改为 `request_path.read_text()`
- **影响**: cycle 可以正常保存

### 8. 规则引擎持仓限制（第 4 处）
- **问题**: `rule_engine_decision` 中还有 `if not positions` 限制
- **修复**: 删除第 5384 行的限制
- **影响**: 规则引擎可以在有持仓时生成订单

### 9. 缺少 signal_source
- **问题**: 规则引擎生成的订单缺少 `signal_source='claude-pa'`
- **修复**: 在 action 中添加 `signal_source='claude-pa'`
- **影响**: 订单可以跳过风控检查

### 10. signal_source 未传递
- **问题**: `order_payload` 中的 `signal_source` 被硬编码为 `self.config.operator_agent`
- **修复**: 改为 `action.get('signal_source') or self.config.operator_agent`
- **影响**: 规则引擎的 `signal_source` 被正确传递
