# Al Brooks 价格行为学 - 概率数据与快速参考

## 一、核心概率表

### 1. 80%规则

| 情境 | 概率 | 含义 |
|------|------|------|
| 突破失败 | 80% | 大多数BO会失败 |
| 反转失败 | 80% | 大多数reversal尝试会失败 |
| TR突破失败 | 80% | TR中的BO多为假突破 |
| 首次逆势entry失败 | 80% | 紧通道中逆势易亏 |

### 2. MTR概率

| 情境 | 概率 | 含义 |
|------|------|------|
| MTR尝试 | 40%成功 | 60%会失败 |
| MTR失败后2 leg MM | 高概率 | 失败常导致等距测量 |
| MAG后MTR尝试 | 60% | 20+bar后出现MAG，60%有MTR尝试 |
| HSB成功反转 | 40% | 60%继续趋势或TR |

### 3. 趋势与通道概率

| 情境 | 概率 | 含义 |
|------|------|------|
| 通道反向突破 | 75% | 通道变TR或反转 |
| 通道同向突破 | 25% | 通道继续趋势 |
| 50%回调后继续 | 60% | 顺势概率 |
| 2/3回调后继续 | 50% | 概率降至五五开 |
| Deep PB后2 leg | 高概率 | 深度回调常有两腿 |

### 4. Gap概率

| 情境 | 概率 | 含义 |
|------|------|------|
| 衰竭缺口被填补 | 60% | 末期gap大概率回补 |
| 测量缺口继续 | 高概率 | 中期gap代表动能 |
| 突破缺口方向 | 高概率 | 早期gap方向正确 |
| Island reversal | 低概率 | Most reversal fails |

### 5. 回调概率

| 情境 | 概率 | 含义 |
|------|------|------|
| 第一leg继续趋势 | 高概率 | H1/L1通常继续 |
| 第二leg入场胜率 | 60% | H2/L2最佳entry |
| 第三leg后趋势 | 下降 | 可能变成TR |
| 4+ leg | - | 可能不是PB而是反转 |
| 20+ bar PB变TR | 50% | 趋势继续概率降半 |

## 二、快速参考表

### 1. 市场状态识别

| 状态 | 特征 | 交易策略 |
|------|------|----------|
| **突破(BO)** | 无明显回调，强动能 | Swing，buy/sell close |
| **紧通道** | 回调<2×bar size | 只顺势，不逆势stop |
| **宽通道** | 较深回调，gap被关闭 | 可limit order scalp |
| **TR** | 双向，20+bar | BLSH，不赌突破 |
| **TTR** | 窄幅，5-10bar | 不交易，等待BO |

### 2. 最佳Setup排序

**高概率 (60%+)**：
1. 小回调趋势中的H2/L2
2. LH MTR（三推后）
3. TR边界的DT/DB
4. 强突破+follow through
5. 强趋势中的50%回调

**中等概率 (50-60%)**：
1. HH MTR
2. 好wedge reversal
3. 紧通道顺势entry
4. MAG后的首次回调

**低概率 (<50%)**：
1. 紧通道中逆势entry
2. TTR中entry
3. Bad wedge reversal
4. 无follow through的BO

### 4. 形态转换关系

```
趋势演化路径：
BO → Tight Channel → Broad Channel → TR

Trend → Minor Reversal → Resume Fail → MTR → New Trend
```

## 三、交易者方程速算

### 1. 盈亏平衡概率

| R:R Ratio | 所需胜率 |
|-----------|----------|
| 1:1 | 50% |
| 1:2 | 33% |
| 1:3 | 25% |

### 2. 期望收益计算

```
期望 = (胜率 × 盈利) - (败率 × 亏损)

示例：
胜率60%，盈利20点，亏损10点
期望 = (0.6 × 20) - (0.4 × 10) = 12 - 4 = 8点/笔
```

### 3. 仓位计算

```
仓位 = 可承受风险金额 / 止损点数

示例：
账户$10,000，风险2% = $200
止损10 ticks = $125 (假设每tick $12.5)
仓位 = $200 / $125 = 1.6 → 1 contract
```

## 四、时间框架参考

### 1. 不同TF的用途

| 时间框架 | 用途 | 注意 |
|----------|------|------|
| 5min | 日内交易 | Al主要使用 |
| 15min | 确认趋势 | 中期方向 |
| 60min | 更大结构 | Swing trading |
| Daily | 大趋势 | 支撑阻力 |

### 2. 日内时间规律

- **开盘后1小时**：高波动，常见BO
- ** midday**：可能TR，波动降低
- **2-2:30pm EST**：可能有尾盘波动
- **收盘前**：机构调整仓位

## 五、常见错误与纠正

| 错误 | 原因 | 纠正 |
|------|------|------|
| 逆势交易 | 想在顶底猜反转 | 等MTR确认，顺势为主 |
| 不止损 | 希望价格回来 | 严格止损，cut loss fast |
| 过度交易 | TTR中强行entry | TTR不交易，等待BO |
| 追突破 | FOMO | 等PB或2nd entry |
| 忽视context | 只看形态 | Context决定一切 |
| 固定思维 | 认为一定会反转 | 记住80%规则 |

## 七、关键记忆口诀

### 趋势交易
```
顺势为王，逆势易伤
小回调强，宽通道弱
High 2买，Low 2卖
移动止损，利润放大
```

### 反转交易
```
MTR重要，三条件要
破线回头再破发
LH比HH更可靠
80%会失败，要记牢
```

### 突破交易
```
突破需确认，follow through重要
80%会失败，不急于追高
等第二腿，或回调再进
假突破多，真突破少
```

### 交易区间
```
TR不赌突破，BLSH为主
TTR不交易，等待为上
Ledge是磁铁，突破会回测
Confusion和Disappointment是特征
```

## 八、紧急情况处理

### 1. 快速止损触发
- 不立即反向
- 评估premise
- 决定re-entry或等待

### 2. 大幅波动
- 检查是否有新闻
- 评估是否是climax
- 考虑减仓或exit

### 3. 连续亏损
- 降低仓位
- 检查策略执行
- 必要时停止交易

### 4. 错过机会
- 不追价
- 等待下一个setup
- 市场永远有机会
