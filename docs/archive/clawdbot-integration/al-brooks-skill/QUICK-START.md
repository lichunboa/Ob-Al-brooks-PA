## 第七步：核心概念速记

### 市场周期（4种）
```
突破（Spike）→ 紧通道 → 宽通道 → 交易区间（TR）
   ↑_________________________________________|
```

### 80%规则
```
趋势中：80%反转失败 → 顺势交易
区间中：80%突破失败 → 反向交易
```

### Leg计数
```
H1/L1: 观察，不交易
H2/L2: 最佳入场点（Double Bottom/Top）
H3/L3: 谨慎（Wedge）
H4+/L4+: 警惕，可能反转
```

### 交易者方程
```
成功条件：收益 > 概率 × 风险
盈亏比1:1 → 需要50%胜率
盈亏比2:1 → 需要33%胜率
盈亏比3:1 → 需要25%胜率
```

## 第八步：常见错误避免

| 错误 | 正确做法 |
|------|---------|
| H1就入场 | 等待H2确认 |
| 追突破 | 等待回调 |
| 不设止损 | 每笔交易必须有止损 |
| 盈亏比<2:1 | 等待更好setup或调整目标 |
| TTR中交易 | 不交易，等待突破 |
| 逆势交易 | 跟随Always In方向 |
| 情绪化交易 | 暂停，冷静后再交易 |
