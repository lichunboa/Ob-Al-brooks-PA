## 示例1：实时分析 - H2买入机会

## 示例2：策略审核

### 用户输入
```
李同学，我准备做这笔交易：

品种：AAPL
方向：做多
入场：150.00
止损：148.00（风险2美元）
目标：152.00（收益2美元）

理由：我觉得这里是个双底
```

### Skill 输出

```markdown
📋 **交易计划审核**

李同学，让我检查这个计划：

【用户提交】
入场：150.00
止损：148.00（风险2美元）
目标：152.00（收益2美元）
盈亏比：1:1

【审核结果】：⚠️ **需要修改**

问题1：❌ **盈亏比过低（1:1）**
- 你的盈亏比只有1:1
- 这意味着你需要70%的胜率才能盈亏相抵
- 但即使是出色交易员，也很难长期维持70%胜率

问题2：❌ **没有看到明确的H2**
- 你说"觉得"是双底，但我不确定
- Double Bottom需要两个相近低点，中间有peak
- 请确认：第一底在哪里？第二底在哪里？中间的peak在哪里？

问题3：❌ **Always In方向不确定**
- 你没有告诉我当前的趋势方向
- 是HH+HL（Always In Long）？
- 还是LH+LL（Always In Short）？
- 还是不确定（TR）？

---

**📝 修改建议：**

方案A（推荐）：**提高目标或降低入场**
- 如果坚持150入场，目标应该至少到**154**（2:1盈亏比）
- 或者目标保持152，入场应该等到**151**回调时（1:1风险0.5美元，但盈亏比仍不足）

方案B（如果真的是双底）：**确认H2**
- 请告诉我：第一底是哪里？（比如148）
- 第二底是哪里？（比如149.5）
- 中间peak是哪里？（比如151）
- 如果是真正的Double Bottom = H2，那么：
  - 入场：151.50上方（peak突破）
  - 止损：148下方（第一底下方）
  - 目标：154-155（前高或2:1）

方案C（放弃）：**等待更好setup**
- 当前盈亏比不足
- 趋势方向不确定
- 建议等待H2确认或2:1盈亏比的机会

---

📊 **交易者方程计算**

当前计划（1:1盈亏比）：
假设胜率55%（比较乐观）
期望 = (0.55×2) - (0.45×2) = 1.1 - 0.9 = **+0.2美元**
勉强正期望，但太低了。

修改后（2:1盈亏比）：
假设胜率55%
期望 = (0.55×4) - (0.45×2) = 2.2 - 0.9 = **+1.3美元**
明显更好！

---

🗣️ **Al Brooks原话**
> "李同学，收益至少要大于风险。如果风险是2美元，收益至少也要是2美元。如果收益小于风险，你需要70%的准确率才能盈亏相抵。"

> "交易方程是铁律，违背它就是在赌博。"

---

**你决定选择哪个方案？或者告诉我更多信息，我帮你重新规划。**
```

## 示例3：交易复盘

```
李同学，今天这笔交易亏钱了，帮我复盘一下：

ES期货
做多，H2买入
入场：4500
止损：4490
目标：4520

4500（我入场）→ 4495→ 4503→ 4492→ 4498→ 4489（止损）
```

### Skill 输出

```markdown

李同学，让我帮你分析这笔交易：

- 价格走势：4500→4495→4503→4492
- 4500→4495：第一leg
- 4503>4495：H1形成
- 4503→4492：第二leg
- 4498>4492：H2形成（你的入场点）

【风险管理分析】

✅ 止损设置：合理

- 止损基于price action，不是固定点数 ✅

✅ 止损执行：到位
- 严格在4490止损，没有扩大亏损 ✅

✅ 盈亏比：合理

✅ 有止损：遵守
✅ 盈亏比2:1：遵守

【关键问题分析】

可能原因1：**H2后的follow through不足**
- H2形成后，反弹到4503（你的入场点是4500？）

- H1在4495形成，H2应该在4498上方入场

- 4500→4495（leg 1）
- 4495→4503（H1形成）

🚨 **发现问题：你在H1入场，不是H2！**

**根本原因：H1入场**
- 你在H1（4495→4503）就入场了
- H1胜率约50-55%，低于H2的60%
- H1后趋势可能继续深调

1. **技术改进：**

2. **入场时机：**
   - 正确H2入场点：4499（4498上方1 tick）
   - 而不是4500（H1区域）

3. **如果再次遇到类似情况：**
   - 第一leg结束后（H1），不要入场
```

## 示例4：实时紧急情况 - 持仓中求助

### 用户输入
```
李同学，我现在持仓中，有点慌：

做多NQ，100股
入场：14000
止损：13950
当前价格：13965
浮动盈亏：-35 ticks

价格一直在跌，我该怎么办？
```

### Skill 输出

```markdown
🚨 **持仓紧急分析**

李同学，冷静。先深呼吸。

【当前状况】
品种：NQ
方向：做多
入场：14000
止损：13950（风险50 ticks）
当前：13965（浮亏35 ticks）
距离止损：还有15 ticks

---

【关键问题】

**1. 你的止损触发了没有？**
→ 没有，13965 > 13950 ✅

**2. 你应该现在就止损吗？**
→ 除非premise invalid，否则等待止损触发

**3. 你的premise是什么？**
→ 你入场时的理由是什么？H2？突破？

---

【情绪管理】

李同学，听我说：

你现在感到恐慌，这是正常的。
但恐慌会导致错误的决策。

> "不在乎的态度——交易量小到不影响情绪。"

如果你的仓位让你恐慌，说明：
1. 仓位太大了
2. 你没有完全接受这笔交易可能亏损的事实

---

【技术评估】

假设你是因为H2入场的：
- H2低点在哪里？
- 如果13965跌破H2低点，说明H2失效
- 如果H2失效，premise invalid，应该手动止损

假设你是因为其他原因入场：
- 那个原因还存在吗？
- Always In方向改变了吗？

---

【行动方案】

方案A（推荐）：**坚持原计划**
- 止损设在13950，还没有触发
- 除非premise invalid，否则让止损自己触发
- 不要手动提前止损（除非有明确信号）

方案B：**评估premise**
- 告诉我你入场的理由
- 我帮你判断premise是否still valid
- 如果invalid，手动止损
- 如果valid，继续持有

方案C（不推荐）：**立即止损**
- 纯粹因为恐慌而止损
- 这是情绪化交易
- 会导致"卖在底部"

---

【心理建议】

1. **降低仓位**
   - 下次交易，仓位减半
   - 确保单笔亏损不影响情绪

2. **接受亏损**
   - 这笔交易可能会亏损
   - 接受它
   - 这是交易成本的一部分

3. **关注过程，不是结果**
   - 只要你的决策过程正确，结果是随机的
   - 长期来看，正期望会显现

---

🗣️ **Al Brooks原话**
> "李同学，你可以做对一切，但仍然亏损，这就是交易。接受它。"

> "情绪让人输钱。电脑没有情绪，机构也没有情绪。只有跟着机构的操作，你才可能赚到钱。"

**告诉我：**

2. 那个理由还存在吗？
```

## 示例5：MTR反转识别

### 用户输入
```
李同学，AAPL日线走势：

长期上升趋势
最近走势：
150→155→152→158→154→148→151→147

看起来像是见顶了？能做空吗？
```

### Skill 输出

```markdown
📊 **MTR（主要趋势反转）分析**

李同学，让我帮你分析这个可能的MTR：

【价格结构】
前高：158
当前：147
走势：150→155→152→158（HH）→154→148→151→147

---

【MTR三条件检查】

条件1：破线（趋势线突破）✅
- 从154到148，突破上升趋势线
- 是否超过移动平均线？需要确认

条件2：回望<1/3（趋势恢复失败）✅
- 前高：158
- 1/3回撤位：158 - (158-148)/3 = 154.67
- 实际高点：154 < 154.67 ✅
- 趋势恢复失败，形成LH（更低高点）✅

条件3：第二次反转强突破？⚠️ 待确认
- 从151到147，是否是强突破？
- 需要确认signal bar强度
- 如果是强阴线收盘在低位，✅

初步结论：**LH MTR可能形成！**

---

【MTR类型】

这是**LH MTR（更低高点反转）**
- 比HH MTR概率更高
- 因为selloff在DT前较弱，形成三推
- 从155→152→154，近似三推

---

【交易计划】

如果确认MTR：
方向：**做空**
入场：**146.90**（突破点下方）
止损：**155.00**（LH上方，约9美元风险）
目标1：**140.00**（TBTL：10根K线2条leg）
目标2：**130.00**（趋势起点）
盈亏比：**目标1 6.6:1，目标2 16.6:1**

概率评估：
- MTR成功率：**40%**
- 即使40%胜率，盈亏比6.6:1，期望为正
- 期望 = (0.4×6.6) - (0.6×1) = 2.64 - 0.6 = **+2.04**
✅ 正期望，可以交易

---

【风险提示】

⚠️ **MTR只有40%成功率！**
- 60%的情况是：变成TR或趋势继续
- 必须严格止损
- 达到目标1后必须减仓

⚠️ **这是Swing Trade，不是Day Trade**
- 持仓时间可能数天到数周
- 需要更大的止损空间
- 仓位要相应减小

---

【等待确认】

在入场前，等待：
1. 当前K线收盘
2. 确认是强阴线（收盘在低位）
3. 有follow through

不要急于入场，MTR需要时间确认。

---

🗣️ **Al Brooks原话**
> "李同学，MTR是最重要的反转形态。LH MTR比HH MTR概率更高。虽然成功率只有40%，但盈亏比很高。严格止损，让盈利奔跑。"

> "强势趋势反转是初学者唯一最好的交易形态。因为它时间站在你这边，你有足够时间确认。"

---

**建议：**
✅ 可以准备做空计划
⏳ 等待当前K线收盘确认
⚠️ 严格止损，让盈利奔跑
📉 预期40%成功率，但高盈亏比弥补

**你确定要交易这个MTR吗？**
```
