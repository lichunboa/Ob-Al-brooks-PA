## 2. Leg计数器

### Bull Trend 计数

```
Price
  │    ● 前高
  │   ╱
  │  ╱  ● H1（第一leg结束）
  │ ╱  ╱│
  │╱  ╱ │
  │   ╱  │ ● H2（第二leg结束）← 最佳入场！
  │  ╱   │╱
  │ ╱    ●
  │╱    ╱│ ● H3（第三leg结束）← 谨慎
  │     ╱ │
  │    ╱  │ ● H4（第四leg）← 警惕，可能反转
  └────────────────────── Time
```

**使用方法：**
1. 确认趋势方向（HH+HL = Bull Trend）
2. 识别回调开始（出现更低的low）
3. 当bar的high > 前一个bar的high → 当前leg结束
4. 开始计数

**规则：**
- H1：观察，不交易
- H2：最佳入场点（Double Bottom）
- H3：可以交易，但谨慎（Wedge Bottom）
- H4+：警惕，可能不是回调而是反转
- **重置：** 每次突破创新高后，重新从H1开始

### Bear Trend 计数（镜像）
- L1：观察
- L2：最佳卖出点（Double Top）
- L3：谨慎（Wedge Top）
- L4+：警惕

## 3. 概率计算器

**输入：**
- 入场价：$___
- 止损价：$___
- 目标价：$___
- 胜率估计：___%（通常40-60%）

**计算：**
```
风险 = |入场价 - 止损价|
收益 = |目标价 - 入场价|
盈亏比 = 收益 / 风险
期望值 = (胜率×收益) - (败率×风险)
仓位大小 = 可承受风险 / 风险
```

**结果解读：**
- ✅ 期望值 > 0：正期望，可以交易
- ⚠️ 期望值 = 0：公平赌局，不建议
- ❌ 期望值 < 0：负期望，放弃

**盈亏平衡胜率：**

| 盈亏比 | 所需胜率 |
|--------|---------|
| 1:1 | 50% |
| 2:1 | 33% |
| 3:1 | 25% |
