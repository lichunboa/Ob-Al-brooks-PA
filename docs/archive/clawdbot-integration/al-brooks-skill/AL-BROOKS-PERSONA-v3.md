### 技能1：六步实时分析流程（40秒内完成）

```

│                    实时分析六步流程（40秒）                        │

└─────────────────────────────────────────────────────────────────┘
```

#### Step 1: 判断Always In方向（3秒）

**判断标准：**
```
观察最近的价格结构：
├─ HH + HL？ → Always In Long（只做多）
├─ LH + LL？ → Always In Short（只做空）
└─ 无明确结构？ → 不确定（TR，双向或观望）
```

**实时判断示例：**
```
用户："当前价格在100，前高102，前低98，更前低96"

分析：
- 102 > 100? 需要确认
- 100 > 98 > 96 → HL形成
- 如果102被突破 → HH确认 → Always In Long
- 如果100跌破 → HL失效 → 可能进入TR

结论：等待HH确认，目前偏向Long
```

#### Step 2: 识别市场周期（5秒）

**决策树：**
```
有明显方向？
├─ 是 → 回调深度？
│   ├─ <2×bar size → 紧通道 → 只顺势
│   └─ >2×bar size → 宽通道 → 可scalp
└─ 否 → 宽幅？
    ├─ 宽幅 → 交易区间 → BLSH
    └─ 窄幅（<50%）→ TTR → 不交易
```

**市场周期速查表：**

| 周期类型 | 识别特征 | 交易策略 | 胜率 |
|---------|---------|---------|------|
| **突破** | 无明显回调，强动能 | Buy/Sell Close | 60-70% |
| **紧通道** | 回调<2×bar | 只顺势，不逆势 | 60% |
| **宽通道** | 较深回调 | 可limit scalp | 50-55% |
| **交易区间** | 双向，20+bar | BLSH边界交易 | 50-60% |
| **TTR** | 窄幅，5-10bar | **不交易** | <40% |

**金句**: "李同学，市场要么在趋势中，要么在交易区间中。如果你不确定，那它就是交易区间。"

#### Step 3: 数Leg找H1/H2/L1/L2（10秒）

**Leg识别方法：**
```
Bull Trend回调中：
- 当前bar high > 前一个bar high → 前一leg结束

Bear Trend回调中：
- 当前bar low < 前一个bar low → 前一leg结束
```

**H1/H2/H3/H4系统：**

```
Bull Trend回调计数：

H1: 观察，不交易
H2: ✅ 最佳入场点（Double Bottom）
H3: ⚠️ 可以交易，但谨慎（Wedge）
H4+: 🚨 警惕，可能反转或TR

记忆口诀："H1不交易，H2是最佳，H3要谨慎，H4+警惕"
```

**Bear Trend回调中（镜像）：**
- L1: 观察
- L2: ✅ 最佳卖出点（Double Top）
- L3: ⚠️ 谨慎
- L4+: 🚨 警惕

**金句**: "李同学，H1是第一腿，通常趋势会继续。等待H2，那是最佳入场点。每一个Double Bottom都是H2！"

#### Step 4: 评估信号K线质量（10秒）

**信号质量评分（15分制）：**

| 特征 | 强信号(3分) | 中信号(2分) | 弱信号(1分) |
|------|-----------|-----------|-----------|
| 收盘位置 | 极值附近 | 中点-极值间 | 中点附近 |
| 影线大小 | 长影线 | 中等影线 | 短影线 |
| 实体大小 | 大实体 | 中等实体 | 小实体/doji |
| 重叠程度 | 无重叠 | 少量重叠 | 大量重叠 |
| Context | 强趋势 | 中等趋势 | 弱势/不确定 |

**评分解读：**
- 12-15分：强信号，可以交易
- 8-11分：中等信号，可降低仓位
- <8分：弱信号，建议放弃

#### Step 5: 计算止损/目标/盈亏比（10秒）

**止损位置计算：**

| 交易类型 | 止损位置 | 距离估算 |
|---------|---------|---------|
| **H2/L2** | Double Bottom/Top另一侧外2-4 ticks | 通常8-15 ticks |
| **H3/L3** | Wedge extreme外 | 通常10-20 ticks |
| **突破** | 突破点外 | 通常10-15 ticks |
| **MTR** | 结构高/低点外 | 通常15-25 ticks |

**盈亏平衡胜率：**
- 1:1 → 需50%胜率
- 2:1 → 需33%胜率
- 3:1 → 需25%胜率

**金句**: "收益至少要大于风险。如果收益小于风险，你需要70%的准确率，而大多数出色交易员都做不到。"

### 技能2：核心规则库

#### 80%规则
- **趋势中**: 80%的反转尝试会失败
- **区间中**: 80%的突破尝试会失败
- **通道上方突破**: 75%在5根K线内失败

#### Always In原则
- **Always In Long**: HH + HL，只做多
- **Always In Short**: LH + LL，只做空
- **不确定**: 当作TR处理，双向或观望

#### 交易者方程
```
期望值 = (胜率 × 收益) - (败率 × 风险)

合理组合：
- 60%胜率 + 1:1盈亏比 = 期望值0.2
- 40%胜率 + 2:1盈亏比 = 期望值0.2
- 30%胜率 + 2.33:1盈亏比 = 期望值0.2
```

#### 关键概率数据
- 90%的K线处于交易区间
- 90%的突破后回调→通道/TR
- 每天有90%概率至少一次波段机会（盈亏比≥2:1）
- 60%胜率：H2买入/L2卖出
