# Al Brooks 价格行为学 - 核心知识摘要

## 一、核心概念与术语

### 1. 市场周期 (Market Cycle)
市场总是处于以下四种状态之一：
- **突破 (BO - Breakout)**：最强趋势，无明显回调
- **紧通道 (Tight Channel)**：强趋势，小回调
- **宽通道 (Broad Channel)**：弱趋势，较深回调
- **交易区间 (TR - Trading Range)**：双向交易，方向不明

**关键概率**：
- 75%的通道会反向突破变成TR或反转
- 25%的通道会继续同方向突破

### 2. 趋势定义
- **多头趋势**：需要更高的低点 (HL - Higher Lows)
- **空头趋势**：需要更低的高点 (LH - Lower Highs)
- **主要高点/低点 (Major)**：创造强突破的新高/新低
- **次要高点/低点 (Minor)**：未创造强突破，只是TR中的一部分

### 3. Always In 方向
- **Always In Long**：强势多头信号后的顺势做多
- **Always In Short**：强势空头信号后的顺势做空

## 二、回调 (Pullback) - 09系列

### 1. 回调定义
- **多头趋势中**：一个bar的low低于前一个bar的low
- **空头趋势中**：一个bar的high高于前一个bar的high
- **隐含回调 (Implied PB)**：在更小时间框架上的回调

### 2. 回调交易规则
| 规则 | 说明 |
|------|------|
| 数腿进场 | 一般等待第2或第3个leg再entry，第1个leg通常继续趋势 |
| 50%回调 | 最重要的回调位，多空交战点，顺势概率较大 |
| 20+ bars | 持续20根bar以上的回调变成TR，趋势继续概率降至50% |
| High/Low计数 | H2买入，L2卖出；DBL = H2，DTL = L2 |

### 3. 回调入场信号
- **H1/H2/H3**：多头趋势中的High 1/2/3买入信号
- **L1/L2/L3**：空头趋势中的Low 1/2/3卖出信号
- **Double Bottom = High 2**
- **Double Top = Low 2**

---

## 三、缺口 (Gaps) - 10-11系列

### 1. 缺口类型
| 类型 | 定义 | 应用 |
|------|------|------|
| 突破缺口 | 趋势早期的缺口 | 方向确认，可测幅 |
| 测量缺口 | 趋势中期的缺口 | 用于Measure Move计算 |
| 衰竭缺口 | 趋势末期的缺口 | 60%概率被填补，警示反转 |

### 2. Micro Gap
- 定义：趋势bar前后两个bar没有重叠且方向一致
- 意义：增加follow through概率

### 3. MAG (Moving Average Gap)
- **条件**：20+根bar在EMA20之上/下
- **意义**：60%可能是趋势最后一浪，随后有MTR尝试
- **双20买点**：首次回调到EMA20是买点

### 4. 缺口与测幅 (Measure Move)
- 缺口代表动能，可用于计算MM目标位
- 从趋势起点到缺口中点的距离 = MM距离

---

## 四、突破 (Breakout) - 15系列

### 1. 80%规则
- **80%的突破会失败**
- 反转也是突破，所以80%的反转尝试会失败

### 2. 强突破信号特征
**多头突破**：
- 大阳线收盘在高位
- 好的跟随bar
- 突破多个阻力位
- 形成gap

**空头突破**：
- 大阴线收盘在低位
- 好的跟随bar
- 突破多个支撑位
- 形成gap

### 3. 第二腿 (2nd Leg)
- 突破后通常有第二腿
- 第二腿陷阱 (2nd Leg Trap)：看似强势的leg实际是陷阱

### 4. 突破模式交易
- **突破前**：双方在TR边界BLSH（低买高卖）
- **突破后**：失败方scale in，等待follow through
- **第二腿形成**：双方达成顺势共识

---

## 五、通道 (Channel) - 14, 17系列

### 1. 紧通道 (Tight Channel)
- **特征**：回调小于平均bar大小的2倍
- **交易**：只顺势交易，逆势stop交易易亏损
- **大时间框架**：相当于突破

### 2. 微通道 (Micro Channel)
- **定义**：无回调的连续bar（每根low不低于前一根low）
- **早期**：相当于突破，可测幅
- **晚期**：可能是衰竭缺口
- **逆势突破**：通常是flag，会有第二次entry

### 3. 小回调趋势 (Small Pullback Trend)
- **最强趋势类型**
- 特征：
  - 1-4根小回调bar（大小为其他bar的一半）
  - 很多上下影线的小bar
  - Gap保持开放
  - 最终回调是之前最大回调的1.5-2倍

### 4. 宽通道 (Broad Channel)
- **特征**：创造的gap很快被关闭（Stair模式）
- **交易**：可在通道顶/底用limit order交易
- **结果**：75%变成TR或反转

---

## 六、交易区间 (Trading Range) - 18系列

### 1. TR定义
- 双向交易区域
- 20+根bar的PB变成TR
- 市场的目的是寻找fair price

### 2. TR特征 (Hallmarks)
- **Confusion**：好坏信号都失效
- **Disappointment**：
  - 看起来要启动的趋势被打断
  - Gap频繁被关闭
  - PB通常回到突破点之外

### 3. 紧交易区间 (TTR)
- **Dead Money**：很难赚钱
- **建议**：不交易，等待突破
- **ledge**：3+根bar有相同high/low，80%会被突破后测试

### 4. TR突破
- 80%的TR突破会失败
- 突破后等待follow through确认

---

## 七、趋势反转 (MTR) - 22系列

### 1. MTR定义
最重要的反转形态，需要三个条件：
1. **破线**：Minor reversal突破趋势线
2. **回望1/3**：趋势恢复但未能达到前高/前低的1/3
3. **破发**：第二次反转有强突破

### 2. MTR类型
| 类型 | 说明 |
|------|------|
| LH MTR | 更低高点的反转，概率更高 |
| HH MTR | 更高高点的反转，需要强弩之末 |
| HL MTR | 更高低点的底部反转 |
| LL MTR | 更低低点的底部反转 |

### 3. MTR概率
- 60%的MTR尝试失败，变成TR或趋势继续
- 40%的MTR成功，形成新趋势

### 4. 选择HH还是LH MTR
- **DT前selloff弱** → 等待LH MTR（三推形成）
- **DT前selloff强** → 等待HH MTR（需要新高作为衰竭点）

### 5. 头肩顶/底 (HSB)
- HSB是LH/HL MTR的一种
- 常有nested HSB和nested DT/DB
- 40%形成swing trade，60%趋势继续或TR

## 八、楔形 (Wedge) - 24, 26系列

### 1. 好楔形的特征
- Stair pattern（阶梯形态）
- 有anti-trend bar
- 趋势线收敛
- 不在TTR中
- 各leg的bar count均衡

### 2. 坏楔形 (Bad Wedge)
- 无stair pattern
- 缺乏anti-trend bar
- 趋势线不收敛
- leg之间bar count差异大

### 3. 楔形作为
- **反转形态**：在趋势末期的wedge top/bottom
- **持续形态**：作为bull/bear flag

---

## 九、止损 (Stop Loss) - 33系列

### 1. 止损设置原则
- **止损决定仓位大小**：先确定logical stop位置，再决定position size
- **使用主要HL/LH**：将止损设在主要高低点之外
- **动态调整**：随趋势推进，将止损移至新的主要HL/LH

### 2. 止损被触发后
- 如果premise仍然有效，可以re-entry
- Wide stop被打到可以重新评估
- 初学者：止损设在signal bar之外
- 高手：wide stop with scale in

---

## 十、测幅 (Measure Move) - 11, 20系列

### 1. 测幅方法
| 方法 | 说明 |
|------|------|
| Gap测幅 | 从趋势起点到缺口中点 |
| TR高度测幅 | TR突破后，TR高度的1倍或2倍 |
| Leg 1 = Leg 2 | 第一段 = 第二段 |
| BO测幅 | 突破点到趋势起点距离的延伸 |

### 2. 多测幅重合
- 当多个MM目标接近时，趋势可能结束
- 可以锁定部分利润

## 十一、关键概率总结

| 情境 | 概率 |
|------|------|
| 80%规则（突破失败） | 80% |
| MTR成功 | 40% |
| MTR失败 | 60% |
| 通道反向突破 | 75% |
| 通道同向突破 | 25% |
| 50%回调后继续趋势 | 60% |
| 2/3回调后继续趋势 | 50% |
| 缺口被填补（衰竭缺口） | 60% |
| TR突破失败 | 80% |
| MAG后MTR尝试 | 60% |
| 第二腿陷阱 | 40% |

## 十二、交易者方程 (Trader's Equation)

成功交易需要：
**Probability × Reward > (1 - Probability) × Risk**

三个变量：
1. Risk（风险/止损距离）
2. Reward（回报/目标位）
3. Probability（胜率）

---

## 十三、核心交易原则

1. **顺势交易**：在趋势中只做顺势，逆势易亏损
2. **等待确认**：BO需要follow through确认
3. **数腿进场**：PB中等待H2/L2信号
4. **止损管理**：使用主要HL/LH，动态调整
5. **测幅止盈**：利用MM目标位管理仓位
6. **概率思维**：没有100%，只有60% vs 40%
7. **Context第一**：同样的形态在不同context意义不同
8. **交易区间不赌突破**：80%会失败
9. **小回调趋势最强**：细水长流才是强势
10. **MTR最重要**：是最佳反转setup
