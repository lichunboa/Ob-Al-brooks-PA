# Al Brooks 价格行为学 - 交易决策流程

## 一、开盘分析流程

### Step 1: 确定大时间框架趋势
```
查看日线/小时线：
├─ 多头趋势？ → 偏向做多
├─ 空头趋势？ → 偏向做空  
└─ TR？ → 双向交易，BLSH
```

### Step 2: 标记关键位置
```
标记图表：
├─ 主要支撑/阻力
├─ 昨日高低点
├─ 重要EMA位置
└─ 潜在MM目标位
```

### Step 3: 分析昨天收盘
```
收盘情况：
├─ 强势收盘？ → 可能延续
├─ 弱势收盘？ → 可能回调
└─ TR收盘？ → 可能继续TR
```

## 三、入场决策树

### 1. 趋势中入场

```
在趋势中（Always In方向确定）：

发现回调 → 开始数leg
    │
    ├─ 1st leg (H1/L1) → 观望，可能继续趋势
    │
    ├─ 2nd leg (H2/L2) → ✅ 最佳entry
    │   ├─ Double Bottom/Top确认
    │   ├─ 在signal bar外挂单
    │   └─ Stop设在主要HL/LH外
    │
    ├─ 3rd leg (H3/L3) → Wedge entry
    │   ├─ 确认wedge形态
    │   ├─ 在wedge extreme外挂单
    │   └─ 注意可能变TR
    │
    └─ 4+ leg → 可能是TR或反转
        └─ 停止顺势交易，等待方向明确
```

### 2. MTR入场

```
寻找反转机会：

    发现潜在top/bottom
           │
           ▼
    是否满足MTR条件？
           │
    ┌──────┴──────┐
    │             │
   是            否
    │             │
    ▼             ▼
 继续评估      继续观察
    │
    ▼
三条件检查：
├─ 1. 破线？ → 趋势线被突破
├─ 2. 回头1/3？ → 恢复<1/3前高/低
└─ 3. 破发？ → 第二次反转强BO
    │
    ▼
选择MTR类型：
├─ DT前selloff弱 → 等待LH MTR
└─ DT前selloff强 → 等待HH MTR
    │
    ▼
Entry：在确认bar外挂单
Stop：在MTR结构外
Target：MM计算或趋势终点
```

### 3. 突破入场

```
发现突破：
    │
    ▼
评估突破强度：
├─ Bar size大？
├─ Close强势？
├─ 突破多个level？
└─ 形成gap？
    │
    ├─ 强势 → 等待follow through
    │       │
    │       ├─ 有follow through → 追或等PB
    │       └─ 无follow through → 可能是假突破
    │
    └─ 弱势 → 不追，等待确认

假突破处理：
    │
    ▼
突破失败，回到TR内
    │
    ▼
在TR另一侧寻找entry
或等待2nd leg trap
```

## 四、止损管理流程

```
入场后：
    │
    ▼
设置初始止损
├─ 多头：主要HL下方/DB下方
└─ 空头：主要LH上方/DT上方
    │
    ▼
监控价格发展
    │
    ├─ 价格顺利运行 → 移动止损
    │   ├─ 新HL/LH形成 → 上移/下移止损
    │   ├─ 达到1R → 可考虑移到breakeven
    │   └─ 达到2R → 锁定部分利润
    │
    └─ 价格回调 → 评估premise
        ├─ Premise valid → 持有，可能加仓
        └─ Premise invalid → Exit
            ├─ 触止损 → 自动exit
            └─ 未触但 premise 变 → 手动exit
```

## 五、止盈决策流程

```
盈利中：
    │
    ▼
评估目标位
├─ MM目标位
├─ R:R目标位（1:2, 1:3）
└─ 结构目标位（DT/DB, wedge完成）
    │
    ▼
分批止盈策略：

目标1（1R）：
├─ 减仓25-50%
├─ 移动止损到breakeven
└─ 剩余继续持有

目标2（2R）：
├─ 再减仓25-50%
├─ 移动止损到目标1
└─ 剩余让利润奔跑

目标3（MM或趋势终点）：
└─ 全部平仓或留下极小部分

或使用移动止损跟随趋势直到：
├─ 主要reversal signal出现
├─ 主要HL/LH被突破
└─ Premise不再valid
```

## 六、错误处理流程

### 1. 止损被触发

```
止损触发：
    │
    ▼
不要立即反向！
    │
    ▼
评估premise：
├─ 仍然valid？ → 寻找re-entry
│   ├─ 同方向更好价格
│   ├─ 调整止损位置
│   └─ 可能减小仓位
│
└─ 已invalid？ → 放弃
    ├─ Trend可能继续
    └─ 等待新setup
```

### 2. 错过机会

```
错过entry：
    │
    ├─ 不追价！
    │
    ├─ 等待：
    │   ├─ 回调到合理位置
    │   ├─ 2nd entry机会
    │   └─ 下一个setup
    │
    └─ 记住：市场永远有机会
```

### 3. 连续亏损

```
连续2-3次亏损：
    │
    ▼
检查：
├─ 是否执行策略？
├─ Market condition是否适合？
└─ Position size是否合适？
    │
    ▼
调整：
├─ 降低仓位50%
├─ 更严格选择setup
└─ 或停止交易，复盘
```

## 七、日内交易时间流程

```
开盘前30分钟：
├─ 分析日线趋势
├─ 标记关键位置
└─ 制定交易计划

开盘后1小时：
├─ 观察开盘行为
├─ 等待initial range形成
└─ 寻找early trend机会

Midday：
├─ 可能是TR
├─ 降低交易频率
└─ 等待明确setup

2:00-2:30pm EST：
├─ 尾盘波动可能
├─ 机构调整仓位
└─ 可能的MTR机会

收盘前：
├─ 评估持仓
├─ 决定是否隔夜
└─ 记录当日交易
```

## 八、每日交易检查清单

### 交易前：
- [ ] 确认大时间框架趋势

- [ ] 设置自动止损

- [ ] 监控premise是否valid

### 出场后：
- [ ] 记录exit原因
- [ ] 评估交易质量
- [ ] 更新交易日志

## 九、决策要点速记

### 是否入场？
```
✅ 入场条件（全部满足）：
1. Clear premise
2. 高概率setup（>50%）
3. R:R >= 1:1
4. Logical stop位置
5. 符合当前market cycle

❌ 不入场情况（任一满足）：
1. TTR中
2. Premise不清晰
3. R:R < 1:1
4. 无法设置合理止损
5. 已连续亏损，情绪不稳
```

### 是否出场？
```
✅ 出场条件（任一满足）：
1. 触发止损
2. Premise invalid
3. 达到目标位
4. 出现reversal signal
5. 主要HL/LH被突破

❌ 不出场（持有）：
1. Premise仍然valid
2. 只是正常回调
3. 未到目标位
4. 趋势仍然健康
```
