# Al Brooks 价格行为学 - 形态识别与入场信号

## 一、回调形态 (Pullback Patterns)

### 1. High/Low 计数系统

```
多头趋势回调计数：
H1 = 第一个更高的高点信号
H2 = 第二个更高的高点信号 (Double Bottom)  
H3 = 第三个更高的高点信号 (Wedge Bottom)
H4/H5 = 复合型底部信号

空头趋势回调计数：
L1 = 第一个更低的低点信号
L2 = 第二个更低的低点信号 (Double Top)
L3 = 第三个更低的低点信号 (Wedge Top)
L4/L5 = 复合型顶部信号
```

### 2. Double Top/Bottom 识别

**Double Top (DTL - Low 2)**
- 两个相近高度的高点
- 中间有 trough
- 在多头趋势中是 bear flag
- 在空头趋势中是 reversal setup

**Double Bottom (DBL - High 2)**
- 两个相近深度的低点
- 中间有 peak
- 在空头趋势中是 bull flag
- 在多头趋势中是 reversal setup

**入场规则**：
- 在DT的第二个top下方sell stop
- 在DB的第二个bottom上方buy stop

### 3. Wedge 识别

**Wedge Top (Low 3)**
- 三推上升形态
- 趋势线收敛
- 可作为 reversal 或 bear flag

**Wedge Bottom (High 3)**
- 三推下降形态
- 趋势线收敛
- 可作为 reversal 或 bull flag

**好的Wedge特征**：
1. Stair pattern（阶梯状）
2. 有 anti-trend bar
3. 趋势线明显收敛
4. 各 leg bar count 均衡
5. 不在TTR中

## 二、趋势反转形态 (MTR Patterns)

### 1. MTR 三部曲

```
顶部反转 (Top Reversal):
1. Minor reversal 破趋势线
2. 趋势恢复但未能达到前高1/3 → 形成LH
3. 第二次反转有强 bear BO → MTR确认

底部反转 (Bottom Reversal):
1. Minor reversal 破趋势线  
2. 趋势恢复但未能达到前低1/3 → 形成HL
3. 第二次反转有强 bull BO → MTR确认
```

### 2. MTR 变体

**HH MTR** (更高高点反转)
- 适合：DT前selloff强的情况
- 需要新高作为衰竭点
- 强弩之末的最后一击

**LH MTR** (更低高点反转)
- 适合：DT前selloff弱的情况
- 三推楔形形成衰竭
- 概率更高的反转形态

**Head and Shoulders**
- 本质：LH MTR (顶部) 或 HL MTR (底部)
- 常有 nested HSB
- 常有 nested DT/DB
- 40%形成swing trade

### 3. MTR 入场信号

**最佳入场**：
- 在TTR中的DT/LH确认后sell
- 在TTR中的DB/HL确认后buy
- 破趋势线后的第二次entry

**止损设置**：
- 设在 shoulder 线之外
- 设在MTR结构的高/低点之外

## 三、突破形态 (Breakout Patterns)

### 1. 强突破特征

**多头强突破**：
- Big bull bar
- Close on high
- 突破多个阻力位
- Good follow through bar
- 形成 gap

**空头强突破**：
- Big bear bar
- Close on low
- 突破多个支撑位
- Good follow through bar
- 形成 gap

### 2. 弱突破特征

**弱突破信号**：
- 小bar突破
- 上/下影线长
- 无 follow through
- 立即回调到突破点内

### 3. 第二腿陷阱 (2nd Leg Trap)

**识别**：
- TR中的第二个leg比第一个强
- 看起来要突破TR
- 实际是诱导交易者的陷阱

**应对**：
- 等待confirmed BO
- 观察是否有 follow through
- 不急于追突破

## 四、通道形态 (Channel Patterns)

### 1. 紧通道 (Tight Channel)

**识别**：
- 回调 < 2倍 average bar size
- 持续顺势bar多
- 逆势bar少且弱

**交易方法**：
- 只顺势交易
- Stop entry：突破前高/低
- Limit entry：回调50%
- 不逆势stop交易（空间太小）

### 2. 微通道 (Micro Channel)

**识别**：
- 无回调（每根low不低于前low）
- 连续5+根顺势bar

**交易方法**：
- 期待至少 one more leg
- Limit order：buy below / sell above
- Stop order：buy above / sell below
- 第一次逆势breakout通常是flag

### 3. 小回调趋势 (Small Pullback Trend)

**识别**（最强趋势）：
- 很多1-4根小回调bar
- Bar大小为其他bar的一半
- 很多上下影线的小bar
- Gap保持开放
- 最终回调 = 1.5-2 × 之前最大回调

**交易方法**：
- 买第一个PB to MA
- 买第一个close below MA (bull)
- 买第一个MAG
- Sell the close（因为是强势）

### 4. 宽通道 (Broad Channel)

**识别**：
- HH/HL (bull) 或 LH/LL (bear)
- 创造的gap很快被关闭
- Stair pattern

**交易方法**：
- 可用limit order在顶/底交易
- 可在50% PB处交易
- 75%变成TR或反转

---

## 五、交易区间形态 (TR Patterns)

### 1. TTR (Tight Trading Range)

**识别**：
- 5-10根小bar
- 高度很窄
- 无明显方向

**特征**：
- Dead money（难赚钱）
- 不建议交易
- 等待BO

### 2. Ledge

**识别**：
- 3+根bar有相同high或low
- 5+根更强

**规则**：
- 80%会被突破
- 80%突破后会测试该位置
- 是强磁铁位

### 3. Triangle

**识别**：
- 趋势线收敛
- 是一种TTR
- Late trend triangle通常是final flag

**交易**：
- Breakout mode（双向都可能）

---

## 六、缺口形态 (Gap Patterns)

### 1. 测量缺口 (Measuring Gap)

**识别**：
- 趋势中期
- 无climax特征
- Trend tight
- 几乎无PB

**测幅**：
- 从趋势起点到gap中点
- 向上/向下延伸相同距离 = MM目标

### 2. 衰竭缺口 (Exhaustion Gap)

**识别**：
- 趋势末期
- 连续大bar
- Context适合PB（如TR顶端）
- 可能是2nd leg trap

**结果**：
- 60%概率被填补
- 第一目标：climax起点
- 第二目标：趋势起点

### 3. MAG (Moving Average Gap)

**识别**：
- 20+ bar在EMA20之上/下
- 首次完全突破EMA20

**意义**：
- 60%是final trend leg
- 40% MTR成功
- 60%继续trend或TR

**交易**：
- 双20买点：首次回调到EMA20

## 七、入场信号汇总

### 1. 顺势入场 (With Trend Entry)

| 信号 | 条件 | 止损位置 |
|------|------|----------|
| H2 Buy | 多头趋势中的Double Bottom | 主要HL下方 |
| L2 Sell | 空头趋势中的Double Top | 主要LH上方 |
| H3 Buy | Wedge Bottom | 主要HL下方 |
| L3 Sell | Wedge Top | 主要LH上方 |
| 50% PB | 强势趋势中的50%回调 | 回调起点 |
| MAG Buy | 20+bar后首次回调EMA20 | EMA下方 |

### 2. 反转入场 (Reversal Entry)

| 信号 | 条件 | 止损位置 |
|------|------|----------|
| LH MTR Sell | 三推后LH形成 | HSB shoulder上方 |
| HH MTR Sell | 新高后衰竭 | HH上方 |
| HL MTR Buy | 三推后HL形成 | HSB shoulder下方 |
| LL MTR Buy | 新低后衰竭 | LL下方 |
| Wedge Reversal | 好wedge形态 | Wedge extreme外 |

### 3. 突破入场 (Breakout Entry)

| 信号 | 条件 | 止损位置 |
|------|------|----------|
| BO Buy | 强突破+follow through | 突破点下方 |
| BO Sell | 强突破+follow through | 突破点上方 |
| 2nd Leg Buy | 突破后PB再突破 | 主要HL下方 |
| 2nd Leg Sell | 突破后PB再突破 | 主要LH上方 |

## 八、最佳交易setup排序

### 高概率Setup (60%+)

1. **小回调趋势中的H2/L2**
   - 顺势+强趋势+合理回调

2. **LH MTR (三推后)**
   - 趋势末期+衰竭+LH确认

3. **TR中的Double Top/Bottom**
   - 边界明确+反转确认

4. **强突破+Good Follow Through**
   - 动能确认+第二腿预期

5. **50%回调在强趋势中**
   - 顺势+关键位+动能持续

### 中等概率Setup (50-60%)

1. HH MTR
2. Wedge Reversal（好wedge）
3. 紧通道顺势entry
4. MAG后的首次回调

### 低概率Setup (<50%)

1. 逆势entry在紧通道中
2. TTR中的entry
3. Bad wedge reversal
4. 无follow through的BO entry

*形态识别是交易基础，但Context决定一切*
