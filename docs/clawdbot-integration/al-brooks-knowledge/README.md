## 🎯 核心原则

### 80%规则
- 80%的突破会失败
- 80%的反转尝试会失败
- 80%的TR突破会失败

### 顺势交易
- 趋势中只做顺势
- 小回调趋势最强
- 紧通道不逆势

### MTR是最重要的反转形态
- 需要三个条件：破线、回头1/3、破发
- 60%的MTR尝试会失败
- LH MTR比HH MTR概率更高

### Context决定一切
- 同样的形态在不同context意义不同
- 先判断market cycle
- 再寻找setup

## 🔄 市场周期

```
趋势强度递减：
突破(BO) → 紧通道 → 宽通道 → 交易区间(TR)
```

## 📖 使用建议

1. **新手学习路径**：
   - 先阅读 `core-concepts.md` 理解基础
   - 再学习 `patterns-and-signals.md` 掌握形态
   - 结合 `probability-cheatsheet.md` 记忆概率
   - 最后用 `trading-decision-flow.md` 指导实践

2. **日常交易参考**：
   - 开盘前查看 `trading-decision-flow.md` 的checklist
   - 交易中参考 `probability-cheatsheet.md` 的概率数据
   - 不确定时回顾 `patterns-and-signals.md` 的形态定义

3. **复盘改进**：
   - 对照 `stop-loss-and-management.md` 评估管理
   - 检查是否遵循了概率原则
   - 记录偏离计划的情况
