### 1.1 六步实时分析流程

当用户发送价格信息或图表时，立即执行以下流程：

```
┌─────────────────────────────────────────────────────────────────┐
│                    实时分析六步流程（40秒内完成）                    │
├─────────────────────────────────────────────────────────────────┤
│ Step 1 (3秒)  →  判断Always In方向                                │
│ Step 2 (5秒)  →  识别市场周期                                     │
│ Step 3 (10秒) →  数Leg找H1/H2/L1/L2                              │
│ Step 4 (10秒) →  评估信号K线质量                                  │
│ Step 5 (10秒) →  计算止损/目标/盈亏比                             │
│ Step 6 (2秒)  →  给出具体交易建议                                 │
└─────────────────────────────────────────────────────────────────┘
```

#### Step 1: 判断Always In方向（3秒）

**判断标准：**
```
观察最近的价格结构：
├─ HH + HL？ → Always In Long（只做多）
├─ LH + LL？ → Always In Short（只做空）
└─ 无明确结构？ → 不确定（TR，双向或观望）
```

**Al Brooks原话：**
> "李同学，看左边的走势。如果市场在左边是强势趋势，右边最大的可能是趋势继续。所以你应该沿着趋势的方向交易。"

**实时判断示例：**
```
用户："当前价格在100，前高102，前低98，更前低96"

分析：
- 102 > 100? 需要确认
- 100 > 98 > 96 → HL形成
- 如果102被突破 → HH确认 → Always In Long
- 如果100跌破 → HL失效 → 可能进入TR

结论：等待HH确认，目前偏向Long
```

#### Step 2: 识别市场周期（5秒）

**决策树：**
```
观察当前价格行为：

有明显方向？
├─ 是 → 回调深度？
│   ├─ <2×bar size → 紧通道 → 只顺势
│   └─ >2×bar size → 宽通道 → 可scalp
└─ 否 → 宽幅？
    ├─ 宽幅 → 交易区间 → BLSH
    └─ 窄幅（<50%）→ TTR → 不交易
```

**市场周期速查表：**

| 周期类型 | 识别特征 | 交易策略 | 胜率 |
|---------|---------|---------|------|
| **突破** | 无明显回调，强动能 | Buy/Sell Close | 60-70% |
| **紧通道** | 回调<2×bar | 只顺势，不逆势stop | 60% |
| **宽通道** | 较深回调 | 可limit scalp | 50-55% |
| **交易区间** | 双向，20+bar | BLSH边界交易 | 50-60% |
| **紧交易区间** | 窄幅，5-10bar | **不交易** | <40% |

**Al Brooks原话：**
> "李同学，市场要么在趋势中，要么在交易区间中。如果你不确定，那它就是交易区间。不确定性是交易区间的标志。"

#### Step 3: 数Leg找H1/H2/L1/L2（10秒）

**Leg识别方法：**
```
Bull Trend回调中：
- 当前bar high > 前一个bar high → 前一leg结束

Bear Trend回调中：
- 当前bar low < 前一个bar low → 前一leg结束
```

**H1/H2/H3/H4系统：**

```
Bull Trend回调计数：

Price
  │    ╱╲        ← 原趋势高点
  │   ╱  ╲
  │  ╱    ╲___
  │ ╱     H1  ╲____   ← 第一leg结束（high更高）
  │╱              ╲___
  │                   ╲___
  │                    H2  ╲____  ← 第二leg（最佳入场）
  │                             ╲___
  │                              H3? ← 第三leg（谨慎）
  └──────────────────────────────────→ Time

入场规则：
- H1: 观察，不交易
- H2: ✅ 最佳入场点（Double Bottom）
- H3: ⚠️ 可以交易，但谨慎（Wedge Bottom）
- H4+: 🚨 警惕，可能反转或TR
```

**实际案例：**
```
用户："价格走势：100→98→99→97→98"

分析：
1. 100→98: 第一leg下降
2. 99 > 98: H1形成（leg结束信号）
3. 99→97: 第二leg下降
4. 98 > 97: H2形成！

结论：H2买入信号，在98上方1 tick挂stop buy
```

**Al Brooks原话：**
> "李同学，你的目标就是在牛市回调时买入。H1是第一腿，通常趋势会继续，所以不交易。等待H2，那是最佳入场点。每一个Double Bottom都是H2！"

#### Step 4: 评估信号K线质量（10秒）

**好的信号K线标准：**

**多头信号K线：**
- ✅ 收盘在K线高位（至少中点上方）
- ✅ 下影线 > 1/2 K线长度
- ✅ 开盘接近前K线低点
- ✅ 与前K线重叠少
- ✅ 实体较大（非doji）

**空头信号K线：**
- ✅ 收盘在K线低位（至少中点下方）
- ✅ 上影线 > 1/2 K线长度
- ✅ 开盘接近前K线高点
- ✅ 与前K线重叠少
- ✅ 实体较大

**信号质量评分：**

| 特征 | 强信号(3分) | 中信号(2分) | 弱信号(1分) |
|------|-----------|-----------|-----------|
| 收盘位置 | 极值附近 | 中点-极值间 | 中点附近 |
| 影线大小 | 长影线 | 中等影线 | 短影线 |
| 实体大小 | 大实体 | 中等实体 | 小实体/doji |
| 重叠程度 | 无重叠 | 少量重叠 | 大量重叠 |
| Context支持 | 强趋势 | 中等趋势 | 弱势/不确定 |

**评分解读：**
- 12-15分：强信号，可以交易
- 8-11分：中等信号，可降低仓位
- <8分：弱信号，建议放弃

**Al Brooks原话：**
> "李同学，最漂亮的牛市信号K线不会与前面的K线重叠太多。如果信号K线是一个阴线，只要收盘在中点上方，也可以是买入信号。"

#### Step 5: 计算止损/目标/盈亏比（10秒）

**止损位置计算：**

| 交易类型 | 止损位置 | 距离估算 |
|---------|---------|---------|
| **H2/L2** | Double Bottom/Top另一侧外2-4 ticks | 通常8-15 ticks |
| **H3/L3** | Wedge extreme外 | 通常10-20 ticks |
| **突破** | 突破点外 | 通常10-15 ticks |
| **MTR** | 结构高/低点外 | 通常15-25 ticks |

**目标位置计算：**

| 目标类型 | 计算方法 | 减仓比例 |
|---------|---------|---------|
| 保守目标 | 1:1盈亏比 | 减仓50% |
| 标准目标 | 2:1盈亏比 或 前高/低 | 减仓25% |
| 延伸目标 | MM目标位 | 持有剩余 |

**盈亏比计算示例：**
```
入场价：$100
止损价：$98（风险$2）
目标价：$104（收益$4）

盈亏比 = 4:2 = 2:1 ✅

如果胜率60%：
期望 = (0.6×4) - (0.4×2) = 2.4 - 0.8 = +1.6 ✅ 正期望
```

**Al Brooks原话：**
> "李同学，收益至少要大于风险。如果风险是2个点，收益至少也要是2个点。如果收益小于风险，你需要70%的准确率才能盈亏相抵，而大多数出色交易员都做不到。"

⚠️ **关键提醒**
