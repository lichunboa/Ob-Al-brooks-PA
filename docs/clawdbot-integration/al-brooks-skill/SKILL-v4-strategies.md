## 第六部分：条件累积评分系统（新增）

### 6.1 评分逻辑

```
每分钟扫描 → 检查6个条件 → 累积分数 → 分级响应

0-60分:   👁️ 观察      (记录，不提醒)
60-80分:  ⚠️ 重点关注  (标记，准备资金)
80-100分: 🚨 提前准备  (发送详细交易计划)
```

### 6.2 6大评分条件

| 条件 | 权重 | 评分标准 |
|------|------|---------|
| **后端信号** | 25% | >0.85=25分, 0.75-0.85=20分, 0.65-0.75=15分, <0.65=0分 |
| **Always In一致** | 20% | 方向明确+信号一致=20分, 明确+不一致=10分, 不确定=5分 |
| **策略匹配度** | 25% | >90%=25分, 80-90%=20分, 70-80%=15分, <70%=0分 |
| **形态质量** | 15% | H2/L2=15分, H1+紧通道=12分, H1+宽通道=8分, 无形态=0分 |
| **盈亏比** | 10% | >3:1=10分, 2-3:1=8分, 1.5-2:1=5分, <1.5:1=0分 |
| **多周期共振** | 5% | 5m+15m+1h同向=5分, 5m+15m同向=3分, 单周期=0分 |

**满分100分，80分以上触发"提前准备"**

### 6.3 分级响应

**Level 1 (0-60分): 观察**
- 记录到观察列表
- 不发送提醒
- 持续监控

**Level 2 (60-80分): 重点关注**
- 标记为"重点关注"
- 每2分钟加速检查
- 发送轻量提醒，显示距离目标还差几分

**Level 3 (80-100分): 提前准备**
- 发送完整交易计划
- 具体入场/止损/目标
- 5分钟倒计时提醒

### 6.4 时间衰减机制

```python
# 防止旧信号干扰
if 信号持续 > 5分钟:
    总分 *= 0.95  # 每分钟衰减5%
if 信号持续 > 15分钟:
    总分 *= 0.90  # 加速衰减
if 信号持续 > 30分钟:
    标记为"过期", 分数清零
```

### 6.5 冷却规则

- BTC: 5分钟内不重复提醒
- ETH: 5分钟内不重复提醒
- SOL: 10分钟内不重复提醒
- 其他: 15分钟内不重复提醒
