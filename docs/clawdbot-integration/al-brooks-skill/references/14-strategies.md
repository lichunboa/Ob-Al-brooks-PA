## 策略一：收线追进（Buy/Sell NOW）

### 策略概览

| 属性 | 内容 |
|------|------|
| **一句话** | 强趋势中，当前K线强势收盘时立即追进 |
| **市场周期** | 急速（Spike）、突破模式 |
| **方向** | 多/空 |
| **盈亏比** | 1.5:1 - 2:1 |
| **风险等级** | ⭐⭐⭐⭐ 高 |
| **胜率** | 50-55% |
| **适用水平** | 高级 |

### 入场条件

**必须满足：**
- [ ] 市场处于**突破模式**或**紧通道**
- [ ] 当前K线为大阳线/大阴线
- [ ] **收盘在K线极值**（阳线收高位，阴线收低位）
- [ ] 有**跟随动能**（micro gap或连续顺势bar）

**理想条件：**
- [ ] 突破多个阻力位
- [ ] 开盘即趋势（Trend from Open）
- [ ] 无明显回调

### 入场执行

| 类型 | 入场方式 | 适用场景 |
|-----|---------|---------|
| **标准** | 当前K线收盘后立即市价入场 | 强趋势确认 |
| **保守** | 等待下1-2根K线确认后入场 | 避免假突破 |

### 止损设置

| 风格 | 止损位置 | 距离 |
|-----|---------|------|
| **标准** | 信号K线相反极值外 | 通常8-15 ticks |
| **保守** | 前一个小波段点外 | 通常10-20 ticks |

### 目标位

| 目标 | 计算方法 | 减仓比例 |
|-----|---------|---------|
| 第一目标 | 1:1.5盈亏比 | 减仓50% |
| 第二目标 | 测量移动（MM） | 减仓25% |
| 第三目标 | 趋势终点 | 持有或全平 |

### 失败信号

- 🚨 下一根K线立即反向
- 🚨 收盘价回到信号K线中部
- 🚨 无跟随动能（no follow through）
- 🚨 突破后快速回到区间内

### 策略对比

| 对比项 | 收线追进 | 高1低1 |
|-------|---------|--------|
| 入场时机 | 立即 | 等待回调 |
| 风险 | 较高 | 中等 |
| 盈亏比 | 较低 | 较高 |
| 胜率 | 50-55% | 55-60% |
| 推荐度 | 谨慎使用 | 优先使用 |

### Al Brooks金句

> "李同学，收线追进是高风险策略。除非你看到极强的动能，否则等待回调，等待H2。"

## 策略二：高1低1（High 1 / Low 1）

### 策略概览

| 属性 | 内容 |
|------|------|
| **一句话** | 趋势中的首次回调结束后，顺势入场 |
| **市场周期** | 趋势延续 |
| **方向** | 多/空 |
| **盈亏比** | 2:1 - 3:1 |
| **风险等级** | ⭐⭐⭐ 中 |
| **胜率** | 55-60% |
| **适用水平** | 中级 |

### 入场条件

**市场背景：**
- [ ] 明确的**Always In方向**
- [ ] 趋势处于**早期或中期**
- [ ] 不是TTR（紧交易区间）

**技术条件：**
- [ ] 出现**第一腿回调**（H1/L1）
- [ ] H1/L1信号K线**收盘强势**
- [ ] 回调深度**<50%**（理想<38.2%）
- [ ] 回调速度**适中**（非急剧）

### 入场执行

| 方式 | 订单类型 | 价格 |
|-----|---------|------|
| **标准** | Stop Order | H1高点上方1 tick（多头） |
| | | L1低点下方1 tick（空头） |
| **保守** | 等待H2确认 | Double Bottom/Top |

### 止损设置

| 风格 | 止损位置 | 说明 |
|-----|---------|------|
| **激进** | 信号K线极值外1-2 ticks | 适合scalping |
| **标准** | 回调起点外2-4 ticks | 适合day trading |
| **保守** | 主要HL/LH外 | 适合swing trading |

### 目标位

| 目标 | 计算方法 |
|-----|---------|
| 第一目标 | 前高/前低测试 |
| 第二目标 | 等距投射（MM） |
| 延伸目标 | 2×MM或趋势终点 |

### 与H2的区别

| 对比 | H1 | H2 |
|-----|----|----|
| 回调leg | 第一腿 | 第二腿 |
| 胜率 | 55% | **60%** |
| Al建议 | 可交易，谨慎 | **最佳入场点** |
| 风险 | 趋势可能继续深调 | 趋势恢复确认度更高 |

### 失败信号

- 🚨 回调深度>50%
- 🚨 H1信号K线收线疲软
- 🚨 形成3+腿回调（可能是TR）
- 🚨 突破后无跟随

### Al Brooks金句

> "李同学，H1可以交易，但H2是最佳入场点。如果你 impatient，H1可以，但降低仓位。"

## 策略三：区间突破回调（Breakout Pullback）

### 策略概览

| 属性 | 内容 |
|------|------|
| **一句话** | 区间突破成功后，等待回调测试突破点，顺势入场 |
| **市场周期** | 突破模式 |
| **方向** | 多/空 |
| **盈亏比** | 2:1 - 3:1 |
| **风险等级** | ⭐⭐⭐ 中 |
| **胜率** | 55-60% |
| **适用水平** | 中级 |

### 入场条件

**突破确认：**
- [ ] **强势突破**区间边界
- [ ] 突破K线**收盘远离区间**
- [ ] 突破后**持续推进**（至少2-3根bar）

**回调特征：**
- [ ] **首次回调**回到突破点附近
- [ ] 回调深度**25%-50%**
- [ ] 测试突破点**不破**（Failed Pullback）

**入场信号：**
- [ ] 出现**High 1/Low 1**信号
- [ ] 价格重新向突破方向运动

### 入场执行

| 风格 | 入场方式 | 风险 |
|-----|---------|------|
| **激进** | 回调触及突破点立即限价入场 | 可能继续回调 |
| **标准** | 等待High 1/Low 1确认后stop入场 | 可能错过 |
| **保守** | 等待Second Entry | 最确认，但盈亏比较差 |

### 止损设置

| 位置 | 适用 |
|-----|------|
| 突破点外2-4 ticks | 标准 |
| 回调极值外 | 保守 |
| 区间另一侧 | 宽松 |

### 目标位

| 目标 | 计算方法 |
|-----|---------|
| 首选 | 区间高度的等距运动（AB=CD） |
| 次选 | 前方磁体（老高/老低） |
| 保守 | 区间高度的50%延伸 |

### 与看衰突破的区别

| 对比 | 区间突破回调 | 看衰突破 |
|-----|------------|---------|
| 时机 | 突破后 | 突破前（区间内） |
| 预期 | 趋势延续 | 突破失败 |
| 方向 | 顺势 | 逆势 |
| 止损 | 突破点外 | 区间边界外 |

### 失败信号

- 🚨 价格重新回到区间内部
- 🚨 回调深度>75%
- 🚨 突破K线未能收盘远离区间
- 🚨 突破点附近横盘整理

### Al Brooks金句

> "李同学，80%的突破会失败。但如果你等到突破确认，然后等回调，胜率就从20%提升到60%。这就是耐心带来的优势。"

## 策略四：20均线缺口（20 EMA Gap）

### 策略概览

| 属性 | 内容 |
|------|------|
| **一句话** | 价格连续20-30根K线未触及20EMA后，首次回调至均线附近顺势入场 |
| **市场周期** | 强趋势回调 |
| **方向** | 多/空 |
| **盈亏比** | 2:1 - 3:1 |
| **风险等级** | ⭐⭐⭐ 中 |
| **胜率** | 55-60% |
| **适用水平** | 中级 |

### 入场条件

**均线关系：**
- [ ] 价格**连续20-30根K线**未触及20EMA
- [ ] 最多不超过**40根**
- [ ] 形成明显的**均线缺口**

**回调特征：**
- [ ] **首次回调**触及或接近20EMA
- [ ] 回调深度**<50%**
- [ ] 回调止于**均线附近**（可略微穿透）

**信号K线：**
- [ ] **High 1/Low 1**形态
- [ ] 信号K线**收盘强势**
- [ ] 显示趋势恢复意图

### 入场执行

| 方式 | 订单类型 | 价格 |
|-----|---------|------|
| 标准 | Stop Order | 信号bar高点上方1 tick |
| 保守 | Limit Order | 均线附近 |

### 止损设置

| 风格 | 止损位置 | 距离 |
|-----|---------|------|
| 激进 | 信号K线极值外1-2 ticks | 较小 |
| 保守 | 重要波段点外2-4 ticks | 较大 |

### 目标位

| 目标 | 位置 |
|-----|------|
| 首选 | 原趋势极值（Old High/Low） |
| 延伸 | 突破极值后的等距投射 |

### K线数参考

| K线数 | 评价 | 行动 |
|-------|------|------|
| <20 | 未达标准 | 不算缺口，不交易 |
| 20-25 | 理想 | 最佳交易区间 |
| 25-30 | 良好 | 可以交易 |
| 30-35 | 谨慎 | 警惕趋势可能结束 |
| >40 | 危险 | 可能大级别趋势，避免 |

### 与第一均线缺口的区别

| 对比 | 20均线缺口 | 第一均线缺口 |
|-----|-----------|------------|
| 回调深度 | 止于均线附近 | 穿透均线对侧 |
| 信号类型 | H1/L1 | H2/L2 |
| 胜率 | 55-60% | 60%+ |
| 风险 | 中等 | 略高（因穿透） |

### 失败信号

- 🚨 K线数>40
- 🚨 回调过深，穿透EMA过远
- 🚨 信号K线收线疲软
- 🚨 均线附近形成横向区间

### Al Brooks金句

> "李同学，双20买点——20+根K线远离EMA后首次回调到均线——这是高概率setup。但记住，如果超过40根，可能是更大级别趋势，不要交易。"

## 策略五至十一速查

### 策略五：第一均线缺口（First MA Gap）

| 项目 | 内容 |
|------|------|
| **入场** | 价格穿透EMA对侧后返回，H2/L2信号 |
| **止损** | 穿透极值外或主要HL/LH外 |
| **目标** | 原趋势极值或MM目标 |
| **胜率** | 60%+ |
| **注意** | 比20均线缺口更复杂，但胜率更高 |

### 策略六：双重顶底（Double Top/Bottom）

| 项目 | 内容 |
|------|------|
| **定义** | Double Bottom = H2, Double Top = L2 |
| **入场** | 第二个顶/底确认后，突破neckline |
| **止损** | 另一侧顶/底外 |
| **目标** | TR高度或MM目标 |
| **胜率** | 55-60% |
| **注意** | 最可靠的形态之一，适合初学者 |

### 策略七：楔形顶底（Wedge Top/Bottom）

| 项目 | 内容 |
|------|------|
| **定义** | 三推收敛形态 |
| **好楔形标准** | Stair pattern + Anti-trend bar + 收敛趋势线 |
| **入场** | 第三推确认后 |
| **止损** | Wedge extreme外 |
| **目标** | TBTL或楔形起点 |
| **胜率** | 50-60%（好楔形）|
| **注意** | 只在趋势末期交易 |

### 策略八：看衰突破（Fade Breakout）

| 项目 | 内容 |
|------|------|
| **定义** | 区间内预期突破失败，反向交易 |
| **入场** | 突破尝试后反向信号 |
| **止损** | 区间边界外 |
| **目标** | 区间另一侧 |
| **胜率** | 60%（80%突破失败）|
| **注意** | 只在区间内使用 |

### 策略九：急赴磁体（Rush to Magnet）

| 项目 | 内容 |
|------|------|
| **定义** | 价格快速向支撑/阻力位运动 |
| **入场** | 接近磁体时反向scalp |
| **止损** | 磁体外 |
| **目标** | 小目标（1:1或1.5:1）|
| **胜率** | 60%+ |
| **注意** | 剥头皮策略，小目标快出场 |

### 策略十：极速与通道（Spike and Channel）

| 项目 | 内容 |
|------|------|
| **定义** | 趋势末期，急速+通道形态 |
| **入场** | 通道起点或末端旗形突破失败 |
| **止损** | 通道极值外 |
| **目标** | 趋势起点或MM目标 |
| **胜率** | 40-50% |
| **注意** | 反转策略，严格止损 |

### 策略十一：末端旗形（Final Flag）

| 项目 | 内容 |
|------|------|
| **定义** | 趋势末期的旗形整理 |
| **入场** | 旗形突破失败 |
| **止损** | 旗形极值外 |
| **目标** | 趋势起点 |
| **胜率** | 40-50% |
| **注意** | 反转策略，只在趋势末期使用 |
