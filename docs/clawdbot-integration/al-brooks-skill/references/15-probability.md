## 一、80%规则（核心法则）

### 1.1 80%失败规则

| 情境 | 失败概率 | 交易含义 |
|------|---------|---------|
| **趋势中的反转尝试** | **80%** | 顺势交易，不抄底摸顶 |
| **区间中的突破尝试** | **80%** | 反向交易，低买高卖 |
| **TR突破** | **80%** | TR中的BO多为假突破 |
| **首次逆势entry** | **80%** | 紧通道中逆势易亏 |

### 1.2 为什么80%会失败

**市场结构原因：**
1. 趋势有惯性，倾向于继续
2. 大多数时间市场处于TR（90%）
3. 真正的趋势反转很少见
4. 很多"反转"只是深度回调

**交易启示：**
```
✅ 顺势交易（趋势中）
✅ 反向交易（区间中）
❌ 不抄底摸顶（趋势中）
❌ 不追突破（区间中）
```

## 三、反转概率

### 3.1 MTR（主要趋势反转）

| 情境 | 概率 | 含义 |
|------|------|------|
| **MTR成功** | **40%** | 形成新趋势 |
| **MTR失败** | **60%** | 变成TR或趋势继续 |
| **MAG后MTR尝试** | **60%** | 20+bar后出现MAG |
| **HSB成功反转** | **40%** | 60%继续趋势或TR |

### 3.2 MTR失败后的走势

```
MTR失败后：
├─ 60% 变成交易区间
├─ 可能继续原趋势
└─ 形成复杂的整理形态
```

**交易启示：**
- MTR交易天然低概率（40%）
- 必须严格止损
- 让盈利奔跑（弥补低胜率）
- 只在趋势末期交易MTR

### 3.3 Wedge反转

| 情境 | 概率 |
|------|------|
| **好Wedge反转** | 50-60% |
| **坏Wedge反转** | <40% |
| **Wedge作为flag持续** | 40-50% |

## 十、概率速查卡

### 10.1 快速决策表

```
交易前问自己：

1. 这是什么市场状态？
   ├─ 趋势 → 80%反转失败 → 顺势交易
   └─ 区间 → 80%突破失败 → 反向交易

2. 这是第几leg？
   ├─ H1/L1 → 50%胜率 → 等待
   ├─ H2/L2 → 60%胜率 → 最佳入场
   └─ H3+/L3+ → <50%胜率 → 谨慎

3. 盈亏比够吗？
   ├─ <1.5:1 → 不建议
   ├─ 1.5:1-2:1 → 可以接受
   └─ >2:1 → 理想

4. 交易方程成立吗？
   ├─ 收益 > 概率×风险 → 交易
   └─ 收益 ≤ 概率×风险 → 放弃
```

### 10.2 紧急情况处理

| 情况 | 概率 | 应对 |
|------|------|------|
| 止损触发 | 必然发生 | 接受，重新评估 |
| 连续2次亏损 | 正常 | 检查执行，继续 |
| 连续3次亏损 | 12.5%(随机) | 降低仓位50% |
| 连续4次亏损 | 6.25%(随机) | 停止，复盘 |
| 错过机会 | 经常发生 | 不追，等下一个 |
