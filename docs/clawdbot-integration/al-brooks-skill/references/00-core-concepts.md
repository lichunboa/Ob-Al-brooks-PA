## 一、基础术语

### 1.1 K线相关

| 术语 | 英文 | 定义 |
|------|------|------|
| **K线/Bar** | Bar/Candle | 单根价格柱，包含开高低收 |
| **实体** | Body | 开盘价与收盘价之间的部分 |
| **影线** | Tail/Shadow/Wick | 最高价/最低价到实体的部分 |
| **上影线** | Upper Tail | 最高点到实体上沿 |
| **下影线** | Lower Tail | 最低点到实体下沿 |
| **强收盘** | Strong Close | 收盘在K线极值附近（如阳线收在高位） |
| **弱收盘** | Weak Close | 收盘在K线中部或有长影线 |
| **光头光脚** | Shaven | 无上下影线 |

### 1.2 趋势相关

| 术语 | 英文 | 定义 |
|------|------|------|
| **多头趋势** | Bull Trend | HH（更高高点）+ HL（更高低点） |
| **空头趋势** | Bear Trend | LH（更低高点）+ LL（更低低点） |
| **更高高点** | HH (Higher High) | 比前一个高点更高的高点 |
| **更高低点** | HL (Higher Low) | 比前一个低点更高的低点 |
| **更低高点** | LH (Lower High) | 比前一个高点更低的高点 |
| **更低低点** | LL (Lower Low) | 比前一个低点更低的低点 |
| **主要高点** | Major High | 创造强突破新高的高点 |
| **主要低点** | Major Low | 创造强突破新低的高点 |
| **次要高点** | Minor High | 未创造强突破，只是TR一部分 |
| **次要低点** | Minor Low | 未创造强突破，只是TR一部分 |

### 1.3 市场周期

| 术语 | 英文 | 定义 |
|------|------|------|
| **突破** | BO (Breakout) | 价格突破关键支撑/阻力位 |
| **回调** | PB (Pullback) | 趋势中的反向运动 |
| **通道** | Channel | 两条趋势线之间的价格运动 |
| **紧通道** | Tight Channel | 回调<2×平均bar size的强趋势 |
| **宽通道** | Broad Channel | 较深回调的弱趋势 |
| **交易区间** | TR (Trading Range) | 双向交易，方向不明 |
| **紧交易区间** | TTR (Tight TR) | 窄幅横盘，5-10根bar |

## 二、核心概念

### 2.1 Always In 方向

**定义**：当前应该永远持有的方向。

| 方向 | 条件 | 交易策略 |
|------|------|---------|
| **Always In Long** | HH + HL | 只做多，任何H2都是买入机会 |
| **Always In Short** | LH + LL | 只做空，任何L2都是卖出机会 |
| **不确定** | 无明确HH/HL或LH/LL | 双向交易或观望 |

**判断流程：**
```
观察最近的价格结构：
├─ 有HH和HL？ → Always In Long
├─ 有LH和LL？ → Always In Short
└─ 混乱无明显结构？ → 不确定（TR）
```

### 2.2 80%规则

**核心法则**：
- 80%的突破会失败
- 80%的反转尝试会失败
- 80%的TR突破会失败

**交易含义**：
```
在趋势中：
├─ 80%的反转尝试失败 → 顺势交易
└─ 不要逆势抄底摸顶

在区间中：
├─ 80%的突破尝试失败 → 反向交易
└─ 在边界低买高卖，不追突破
```

### 2.3 交易者方程

**公式**：
```
期望值 = (胜率 × 盈利) - (败率 × 亏损)

简化条件：收益 > 概率 × 风险
```

**盈亏平衡表**：
| 盈亏比 | 所需胜率 |
|--------|---------|
| 1:1 | 50% |
| 1:2 | 33% |
| 1:3 | 25% |
| 1:4 | 20% |

**实际应用**：
```
场景：H2买入
假设：胜率60%，盈亏比2:1

期望 = (0.6 × 2) - (0.4 × 1) = 1.2 - 0.4 = +0.8

结论：正期望，可以交易
```

## 三、形态术语

### 3.1 回调形态

| 形态 | 英文 | 定义 | 交易含义 |
|------|------|------|---------|
| **H1** | High 1 | 多头趋势回调第一腿 | 不交易，观察 |
| **H2** | High 2 | 多头趋势回调第二腿 | 最佳买入点 |
| **H3** | High 3 | 多头趋势回调第三腿 | 谨慎买入 |
| **L1** | Low 1 | 空头趋势回调第一腿 | 不交易，观察 |
| **L2** | Low 2 | 空头趋势回调第二腿 | 最佳卖出点 |
| **L3** | Low 3 | 空头趋势回调第三腿 | 谨慎卖出 |
| **双底** | DB (Double Bottom) | 两个相近低点 | = H2，买入信号 |
| **双顶** | DT (Double Top) | 两个相近高点 | = L2，卖出信号 |

### 3.2 反转形态

| 形态 | 英文 | 定义 | 成功率 |
|------|------|------|--------|
| **MTR** | Major Trend Reversal | 主要趋势反转 | 40% |
| **楔形底** | Wedge Bottom | 三推下降后反转 | 视context |
| **楔形顶** | Wedge Top | 三推上升后反转 | 视context |
| **头肩顶** | HSB Top | 左-头-右结构 | 40% |
| **头肩底** | HSB Bottom | 左-头-右结构 | 40% |

### 3.3 持续形态

| 形态 | 英文 | 定义 |
|------|------|------|
| **牛市旗** | Bull Flag | 多头趋势中的下降通道 |
| **熊市旗** | Bear Flag | 空头趋势中的上升通道 |
| **三角旗** | Pennant | 小型的对称三角形 |
| **末端旗** | Final Flag | 趋势末期的旗形，常反转 |

## 四、订单类型

### 4.1 入场订单

| 订单类型 | 英文 | 使用场景 |
|---------|------|---------|
| **市价单** | Market Order | 突破时追进（收线追进策略） |

| 订单类型 | 英文 | 使用场景 |

| **止盈限价** | Take Profit Limit | 达到目标位获利 |

## 五、测量与计算

### 5.1 测幅（Measure Move）

| 类型 | 计算方法 |
|------|---------|
| **Gap MM** | 趋势起点到gap中点，延伸相同距离 |
| **TR Height MM** | TR高度，从突破点延伸 |
| **Leg MM** | Leg 1 = Leg 2 |
| **BO MM** | 突破距离，从突破点延伸 |

### 5.2 概率术语

| 术语 | 含义 |
|------|------|
| **高概率** | 60%+ 胜率 |
| **中等概率** | 50-60% 胜率 |
| **低概率** | <50% 胜率 |
| **正期望** | 长期盈利的交易 |
| **负期望** | 长期亏损的交易 |

## 七、快速参考卡

### 7.1 市场状态判断速查

```
观察图表（3秒判断）：

有明显方向？
├─ 是 → 回调深度？
│   ├─ 小（<2×bar）→ 紧通道 → 只顺势
│   └─ 大（>2×bar）→ 宽通道 → 可scalp
└─ 否 → TR
    ├─ 宽幅 → BLSH交易
    └─ 窄幅（TTR）→ 不交易，等待
```

### 7.2 入场信号速查

| 市场状态 | 最佳信号 | 止损位置 |
|---------|---------|---------|
| 紧通道多头 | H2 Buy | 主要HL下方 |
| 紧通道空头 | L2 Sell | 主要LH上方 |
| 宽通道多头 | 50% PB Buy | PB起点下方 |
| 宽通道空头 | 50% PB Sell | PB起点上方 |
| TR多头 | DB Buy | 区间底部下方 |
| TR空头 | DT Sell | 区间顶部上方 |

### 7.3 退出信号速查

| 情况 | 行动 |
|------|------|
| 触发止损 | 立即退出，评估re-entry |
| Premise无效 | 手动退出，不等止损 |
| 达到目标 | 按计划减仓或全平 |
| 主要反转信号 | 考虑获利了结 |

## 八、常见误区

### 8.1 术语混淆

| 错误理解 | 正确理解 |
|---------|---------|
| H1就交易 | H1不交易，等待H2 |
| 所有反转都交易 | 80%反转失败，只交易高概率 |
| Minor HL当止损 | 止损只放在Major HL/LH |
| 突破就追 | 80%突破失败，等回调 |

### 8.2 概念混淆

| 错误理解 | 正确理解 |
|---------|---------|
| Wedge一定会反转 | Wedge可作为flag持续 |
| MTR成功率高 | MTR只有40%成功率 |
| TR中赌突破 | TR中80%突破失败 |
| 紧通道逆势scalp | 紧通道逆势易亏 |

## 九、记忆口诀

### 9.1 趋势交易口诀
```
顺势为王，逆势易伤
小回调强，宽通道弱
High 2买，Low 2卖
移动止损，利润放大
```

### 9.2 反转交易口诀
```
MTR重要，三条件要
破线回头再破发
LH比HH更可靠
80%会失败，要记牢
```

### 9.3 突破交易口诀
```
突破需确认，follow through重要
80%会失败，不急于追高
等第二腿，或回调再进
假突破多，真突破少
```

### 9.4 交易区间口诀
```
TR不赌突破，BLSH为主
TTR不交易，等待为上
Ledge是磁铁，突破会回测
Confusion和Disappointment是特征
```
