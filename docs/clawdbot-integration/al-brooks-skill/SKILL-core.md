## 核心分析框架

### Always In 判断（3秒）

```
观察最近的价格结构：
├─ HH + HL？ → Always In Long（只做多）
├─ LH + LL？ → Always In Short（只做空）
└─ 无明确结构？ → 不确定（TR，双向或观望）
```

> "李同学，看左边的走势。如果市场在左边是强势趋势，右边最大的可能是趋势继续。"

### 市场周期识别（5秒）

```
有明显方向？
├─ 是 → 回调深度？
│   ├─ <2×bar size → 紧通道 → 只顺势
│   └─ >2×bar size → 宽通道 → 可scalp
└─ 否 → 宽幅？
    ├─ 宽幅 → 交易区间 → BLSH
    └─ 窄幅（<50%）→ TTR → 不交易
```

| 周期类型 | 识别特征 | 交易策略 | 胜率 |
|---------|---------|---------|------|
| **突破** | 无明显回调，强动能 | Buy/Sell Close | 60-70% |
| **紧通道** | 回调<2×bar | 只顺势，不逆势 | 60% |
| **宽通道** | 较深回调 | 可limit scalp | 50-55% |
| **交易区间** | 双向，20+bar | BLSH边界交易 | 50-60% |
| **TTR** | 窄幅，5-10bar | **不交易** | <40% |

> "李同学，市场要么在趋势中，要么在交易区间中。如果你不确定，那它就是交易区间。"

### H1/H2/H3 回调系统（10秒）

```
Bull Trend回调中：
- 当前bar high > 前一个bar high → 前一leg结束
- H1: 观察，不交易
- H2: ✅ 最佳入场点（Double Bottom）
- H3: ⚠️ 可以交易，但谨慎（Wedge）
- H4+: 🚨 警惕，可能反转

Bear Trend回调中（镜像）：
- L1: 观察
- L2: ✅ 最佳卖出点（Double Top）
- L3: ⚠️ 谨慎（Wedge Top）
- L4+: 🚨 警惕

记忆口诀："H1不交易，H2是最佳，H3要谨慎，H4+警惕"
```

> "李同学，H1是第一腿，通常趋势会继续。等待H2，那是最佳入场点。每一个Double Bottom都是H2！"

### 信号K线质量评分（10秒）

| 特征 | 强信号(3分) | 中信号(2分) | 弱信号(1分) |
|------|-----------|-----------|-----------|
| 收盘位置 | 极值附近 | 中点-极值间 | 中点附近 |
| 影线大小 | 长影线 | 中等影线 | 短影线 |
| 实体大小 | 大实体 | 中等实体 | 小实体/doji |
| 重叠程度 | 无重叠 | 少量重叠 | 大量重叠 |
| Context | 强趋势 | 中等趋势 | 弱势/不确定 |

- 12-15分：强信号，可以交易
- 8-11分：中等信号，可降低仓位
- <8分：弱信号，建议放弃

### 止损/目标计算（10秒）

| 交易类型 | 止损位置 | 目标位置 |
|---------|---------|---------|
| H2/L2 | DB/DT另一侧外2-4 ticks | 前高/低或2:1 |
| H3/L3 | Wedge extreme外 | MM目标位 |
| 突破 | 突破点外 | 区间高度等距 |
| MTR | 结构高/低点外 | TBTL或趋势起点 |

**盈亏平衡胜率：**
- 1:1 → 需50%胜率
- 2:1 → 需33%胜率
- 3:1 → 需25%胜率

> "收益至少要大于风险。如果收益小于风险，你需要70%的准确率，而大多数出色交易员都做不到。"

## MTR（主要趋势反转）核心

**三条件（必须全部满足）：**
1. **破线** — Minor reversal突破趋势线
2. **回望<1/3** — 趋势恢复失败，形成LH或HL
3. **第二次反转强突破** — 强信号K线+follow through

**概率：** 40%成功，但盈亏比通常2:1+，期望值为正

> "李同学，MTR是最重要的反转形态。虽然成功率只有40%，但盈亏比很高。严格止损，让盈利奔跑。"

> MTR 详细分析见 `references/strategies-detailed.md` 和 `al-brooks-knowledge/deep-dive-reversals.md`
